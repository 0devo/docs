Hover over a dotted term anywhere in the docs to see a short definition. This page lists them all.

| Term | Meaning |
| --- | --- |
| <Tooltip tip="A giveaway where the prize is awarded by random draw when the timer ends.">Giveaway</Tooltip> | A prize event members enter and winners are drawn from. |
| <Tooltip tip="A giveaway where the first people to claim win immediately.">Drop</Tooltip> | An instant giveaway: first to claim wins. |
| <Tooltip tip="The interactive panel where you review and adjust a giveaway before publishing.">Studio</Tooltip> | The panel used to configure a giveaway with a live preview. |
| <Tooltip tip="Saved giveaway settings you can reuse.">Template</Tooltip> | A named set of giveaway settings. |
| <Tooltip tip="Extra chances to win on top of the normal one entry.">Bonus entries</Tooltip> | Additional entries for roles, levels, votes and more. |
| <Tooltip tip="Redrawing winners after a giveaway has ended.">Reroll</Tooltip> | Picking replacement or new winners. |
| <Tooltip tip="Freezing the countdown without losing time.">Pause</Tooltip> | Stops the timer; resuming restores the remaining time. |
| <Tooltip tip="Members confirm a prize with one button; unclaimed prizes are rerolled.">Auto-claim</Tooltip> | Automatic claim window with rerolls. |
| <Tooltip tip="Roles allowed to run giveaway commands without Manage Server.">Giveaway Manager role</Tooltip> | A role you trust to manage giveaways. |
| <Tooltip tip="The server-specific badge members can display next to their name.">Official server tag</Tooltip> | A tag members show on their profile for your server. |
| <Tooltip tip="Experience points earned by chatting and being in voice channels.">XP</Tooltip> | Points that raise a member's level. |
| <Tooltip tip="A paid plan applied to one server.">Premium tier</Tooltip> | Tier 1, 2 or 3 of Premium for a server. |
| <Tooltip tip="Text sent before a command, for example g!">Prefix</Tooltip> | What you type before a text command. Default `g!`. |
| <Tooltip tip="A message re-posted so it stays near the bottom of a channel.">Sticky message</Tooltip> | A message that keeps reappearing at the bottom of a channel. |
| <Tooltip tip="A channel where popular messages are reposted.">Starboard</Tooltip> | A showcase channel for messages with enough reactions. |
