# Community, moderation, and utility tools

GiveawayX is not limited to prize events. Its bot source includes Discord community, moderation, information, and entertainment features that can be enabled or restricted per server.

## Channel controls

| Feature | Command | Notes |
| --- | --- | --- |
| Message cleanup | `/clear` | Supports amount, user filtering, filter choice, regex, skipping pinned messages, and a dry-run mode. |
| Channel lock | `/lock` and `/unlock` | Changes sending access; optional channel, role, duration, and reason fields are available. |
| Channel visibility | `/hide` and `/show` | Hides or reveals a channel to members/roles, with a duration available when hiding. |
| Slow mode | `/slowmode` | Applies a selected time to a target/current channel. |

Grant these commands only to trusted staff. Their Discord effects can change access for many members at once.

## Community profiles and interaction

| Feature | Command | Behaviour |
| --- | --- | --- |
| AFK | `/afk` | Stores an optional AFK reason and global state, with mention tracking in server data. |
| Reputation | `/rep` | Awards a reputation point to another user. |
| Levels | `/rank`, `/top` | Shows server XP rank and ranked leaderboard data. |
| Random selection | `/pick` | Selects an item from supported sources such as reactions, role members, number range, or a word list. |
| Games | `/rps`, `/xo` | Supports a challenge/AI rock-paper-scissors mode and a two-user XO game. |

## Information and content tools

`/server`, `/user`, `/avatar`, `/channelinfo`, `/roleinfo`, and `/messageinfo` retrieve Discord information. `/timestamps` creates Discord-readable timestamp values. `/meme` retrieves supported funny-media formats. `/translate` supports text, a message, images through OCR, PDFs, and multiple attachments. `/steal` accepts up to ten emoji or sticker sources.

## Settings-based restrictions

The server model retains disabled channels, disabled roles, and disabled commands. Use these controls to limit disruptive features in support channels, staff channels, or public high-traffic areas.
