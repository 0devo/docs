# GiveawayX Documentation

GiveawayX is a Discord giveaway platform that combines a configurable bot with a server management dashboard. It is designed for communities that need more than a simple prize draw: administrators can control eligibility, scheduling, winner rewards, presentation, logging, engagement tools, and premium server customisation from one system.

![GiveawayX dashboard giveaway manager](/assets/dashboard-giveaways.webp)

> This documentation reflects the supplied GiveawayX bot and dashboard source. It distinguishes enabled features from dashboard items that are explicitly marked **Coming Soon** or **Premium** in the current interface.

| Area | What it covers |
| --- | --- |
| **Giveaways** | Draft-based creation, eligibility checks, bonus entries, templates, scheduling, live management, drops, voice giveaways, and rerolls. |
| **Dashboard** | Server settings, the giveaway studio, embeds, welcome messages, Starboard, sticky messages, logs, audit history, backups, and subscription controls. |
| **Community tools** | Counting, leveling, temporary voice channels, reputation, AFK, utility commands, and content tools. |
| **Automation** | Scheduled giveaways, recurring schedules, sticky reposting, notifications, winner DMs, winner threads, logs, backups, and webhooks. |

## Product terminology

A **server** is a Discord guild managed by GiveawayX. A **giveaway** is a published prize event, while a **draft** is the editable configuration used before publishing or scheduling it. A **template** is a reusable giveaway configuration. **Premium Tier 1** and **Premium Tier 2** unlock different feature limits and customisation options; check [Feature availability](/reference/feature-availability) before relying on a gated option.
