GiveawayX is a Discord bot built around one idea: **giveaways that just work**. Start one in seconds, tune every rule when you need to, and trust it to finish on time, draw fair winners and let you fix anything that goes wrong.

## Everything in the bot

<AccordionGroup>
  <Accordion title="Giveaways" icon="gift" defaultOpen>
    Standard giveaways, instant **drops**, first or last to type games, scheduled and repeating giveaways, reusable templates and a **Studio** panel with a live preview. Entry can use a button or a reaction.
  </Accordion>
  <Accordion title="Rules and fairness" icon="scale-balanced">
    Required roles, blacklists, account and server age, message counts, levels, boosts, official server tag, captcha, suspicious username detection and screenshot verification for social media tasks.
  </Accordion>
  <Accordion title="Winners" icon="trophy">
    DMs to winners and hosts, private or public winner threads, automatic winner roles, one-button prize claiming with automatic rerolls, and a manual reroll with a clear preview.
  </Accordion>
  <Accordion title="Server tools" icon="toolbox">
    Leveling with text and voice XP, starboard, sticky messages, welcome and goodbye messages, AFK status, a translator for text, images and files, and per-command customization.
  </Accordion>
  <Accordion title="Languages" icon="globe">
    17 languages, set per server. See [Language](/features/language).
  </Accordion>
</AccordionGroup>
