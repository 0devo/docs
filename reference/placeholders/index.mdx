A **placeholder** is a word in curly braces, like `{user}`. When the bot sends your message it swaps each placeholder for a real value, so one message can greet every member by name or announce the right prize.

```text
Congratulations {winners_list}! You won {prize} in {server}.
```

becomes

```text
Congratulations @Alex! You won Discord Nitro in My Server.
```

## Which placeholders can I use where?

Each feature understands its **own** set of placeholders. A placeholder from one feature will not work in another.

## Rules that apply everywhere

<Check>Type them exactly as shown, including the curly braces, and keep the spelling the same.</Check>
<Check>You can use the same placeholder several times in one message.</Check>
<Warning>
A placeholder the feature does not know is left **as plain text**, so `{typo}` will appear literally in the message. Always preview before you publish.
</Warning>
<Note>
Some features need a setting or Premium tier before placeholders work. For example, sticky messages need **Placeholders** turned on, which requires Tier 1.
</Note>
