## Giveaways

<AccordionGroup>
  <Accordion title="Who can start a giveaway?" icon="user-shield">
    Anyone with Administrator, Manage Server or a **Giveaway Manager role**. See [Permissions](/concepts/permissions).
  </Accordion>
  <Accordion title="Can I change a giveaway after it started?" icon="pen">
    Yes. `/gedit` changes the prize, duration, winners, requirements and more while it is running. Ended giveaways cannot be edited.
  </Accordion>
  <Accordion title="A winner did not claim. What now?" icon="user-clock">
    Use `/greroll` with `replace` to replace only that winner, or enable `auto_claim` so unclaimed prizes are rerolled automatically.
  </Accordion>
  <Accordion title="Is the draw fair?" icon="scale-balanced">
    Winners are picked at random from the valid entries. Extra chances only come from bonus entries that the host sets up in advance.
  </Accordion>
  <Accordion title="A giveaway did not end on time" icon="wrench">
    Run `/gfix` on it. It finds the problem and repairs it. See [Managing giveaways](/giveaways/managing).
  </Accordion>
  <Accordion title="Can I run giveaways in advance?" icon="calendar">
    Yes. Use `/gschedule`. See [Scheduling](/giveaways/scheduling).
  </Accordion>
  <Accordion title="How long can a giveaway last?" icon="clock">
    Up to 60 days on Free, and longer on Premium. See [Durations](/concepts/durations).
  </Accordion>
  <Accordion title="Can members enter by reacting?" icon="face-smile">
    Yes, with Premium Tier 1. Otherwise members press the Enter button.
  </Accordion>
</AccordionGroup>

## Premium

<AccordionGroup>
  <Accordion title="Is Premium per user or per server?" icon="star">
    Per **server**.
  </Accordion>
  <Accordion title="Is there a free trial?" icon="gift">
    Yes, a one-time 3-day Tier 1 trial per server.
  </Accordion>
  <Accordion title="What happens when Premium ends?" icon="hourglass-end">
    Premium features stop, limits return to Free, and your saved settings and XP data are kept.
  </Accordion>
  <Accordion title="How do I move Premium to another server?" icon="arrow-right-arrow-left">
    The server owner can use `/premium-transfer` for a Tier 2 subscription.
  </Accordion>
</AccordionGroup>

## Other features

<AccordionGroup>
  <Accordion title="Why is my level not going up?" icon="chart-line">
    Leveling needs an active Premium subscription on the server. Also check you are not in an excluded channel or role.
  </Accordion>
  <Accordion title="How do I change the bot's language?" icon="globe">
    Use `/setlang`. See [Language](/features/language).
  </Accordion>
  <Accordion title="How do I change the prefix?" icon="exclamation">
    Prefixes are set per server on the dashboard. The default is `g!`.
  </Accordion>
</AccordionGroup>

## Using slash commands

Type `/` in a server message box, choose a command from Discord's menu, fill its required options, and send it. The [command guide](/commands/overview) links to examples and option details. On mobile, press the command button beside the composer or type `/` to open the same picker. Prefix commands such as `g!gstart` are a separate option; see [Prefix commands](/commands/prefix).
