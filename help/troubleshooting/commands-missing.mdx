---
title: "Slash commands are missing"
description: "Make the bot commands show up."
icon: "slash"
---

<Steps>
  <Step title="Check the command is not hidden">A server can hide or disable commands. See [Command customization](/features/command-customization).</Step>
  <Step title="Check your permissions">Some commands only show for members with Manage Server or Manage Messages.</Step>
  <Step title="Try the prefix">Type `g!help` (or your own prefix). If that works, only slash commands are affected.</Step>
  <Step title="Ask for help">If it still does not appear, ask in the [support server](https://discord.gg/86jArY28hj).</Step>
</Steps>
