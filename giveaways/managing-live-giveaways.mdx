# Managing live giveaways

Once a giveaway is published, GiveawayX provides dedicated commands and dashboard API routes for its lifecycle. Use the giveaway ID or the dashboard event list to identify the correct event before performing a destructive action.

| Action | Command | Use case |
| --- | --- | --- |
| List events | `/glist` | Show active or ended giveaways, optionally filtered by status or channel. |
| Edit | `/gedit` | Change supported event properties on an active or scheduled giveaway. |
| Pause | `/gpause` | Temporarily stop an active event. |
| Resume | `/gresume` | Resume a paused event. |
| End | `/gend` | Finish an active giveaway early. |
| Reroll | `/greroll` | Draw one or more replacement winners, with an option to exclude previous winners. |
| Repair | `/gfix` | Attempt to fix common issues with an active giveaway; this is declared as an Administrator command. |
| Delete | `/gdelete` | Remove the giveaway. |

## Special giveaway modes

**Drop giveaways** use `/gdrop` and award the prize to the first eligible claimant. **Voice giveaways** use `/gvoice`, which can take a voice or stage channel, duration, prize, winner count, text channel, and status-update choice. `/glast` starts a last-person-standing style event using its selected mode.

## Editing limits

The bot’s edit command accepts the giveaway ID plus prize, duration, winners, images, thumbnails, required/bypass/blacklist/winner roles, description, host, announcement copy, account/server-age settings, extra-entry data, repeat count, and sticky state. The dashboard source makes an important distinction: uploaded images and thumbnails are create-only and cannot be changed after publishing through the dashboard form.

## Monitoring

Enable giveaway logs so staff can audit starts, endings, edits, deletions, rerolls, pauses, resumes, drops, fixes, and scheduled events. The dashboard also offers giveaway logs, dashboard logs, audit-log views, active/ended event lists, public giveaway pages, and giveaway statistics endpoints.
