# Eligibility and rewards

GiveawayX supports layered eligibility controls. Use only the controls that match an event’s published rules, and test high-stakes events before launch so staff can verify that the intended members qualify.

## Role and activity eligibility

| Rule | Options |
| --- | --- |
| **Required roles** | Require any one selected role, all selected roles, or at least a chosen minimum. A role-hold duration can require members to have held a qualifying role continuously for a number of minutes. |
| **Bypass roles** | Allow selected roles to skip all requirements, or create scoped bypass rules that skip only selected checks. Multiple matching bypass roles can combine or use only the highest-ranked role. |
| **Blacklist roles** | Block members with any, all, at least a minimum, or more than an allowed maximum of selected roles. |
| **Account and join age** | Require minimum Discord account age and minimum time spent in the server. |
| **Message activity** | Require a message count, optionally limited to selected channels and/or selected roles. |
| **Level and server tag** | Require a minimum GiveawayX level or a member profile displaying the server tag. |

The `/gstart` and `/gschedule` commands expose the main requirements through options such as `required_roles`, `requirement_bypass_roles`, `blacklist_roles`, `joined_age`, `account_age`, `required_messages`, `required_level`, and `required_official_tag`.

## Bonus entries

Bonus rules increase a member’s entry count when they match an event condition.

| Bonus source | Example use |
| --- | --- |
| Role | Give supporters or event roles extra entries. |
| Level or XP | Reward engagement-system milestones. |
| Streak | Reward an established giveaway participation streak. |
| Server tag | Reward members displaying the official tag. |
| Specific user | Grant a fixed bonus to a nominated member. |
| Vote | Award entries for the supported vote/booster condition. |

When multiple rules match, choose **Stack** to add them together or **Priority** to apply only the highest applicable bonus. A maximum extra-entry value can cap total bonus entries per participant; `0` means no cap.

## Winner rewards

Winner roles can be assigned immediately and permanently. Advanced winner-role rules support delayed assignment, temporary duration, reward amounts, XP/level rewards, and removal of previous winners when the rotation rule requires it. You can also enable direct messages for winners and hosts with per-event custom text.

## Winner cooldowns

A giveaway can override the server-wide winner cooldown. The override blocks recent winners of any server giveaway from entering the new one. Leave the field empty to inherit the global default, set `0` to disable the cooldown for that event, or enter a number of minutes for a distinct event-level period.
