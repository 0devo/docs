# Giveaway Manager

The dashboard’s giveaway area combines the full **Giveaway Studio** with event administration. It includes server-wide event lists, creation, individual event viewing/editing/deletion, stats, a test-message action, templates, giveaway message templates, participant blacklist records, and giveaway logs.

## Dashboard capabilities

| Area | Supported operations |
| --- | --- |
| **Giveaways** | List, create, read, update, and delete event records; retrieve statistics; send a test message. |
| **Templates** | List, create, update, and delete reusable giveaway templates. |
| **Message templates** | List, create, and delete giveaway message-template entries. |
| **Blacklist** | List, add, and remove giveaway-blacklisted users. |
| **Logs** | Read giveaway log records. |

## Use the right layer

Use the dashboard when you need the richest draft editor, visual preview, image controls, and server settings. Use slash commands when staff are operating inside Discord. Both interfaces operate against the same giveaway model, so staff should avoid editing the same event simultaneously from different surfaces.

## Public event information

The dashboard source includes a public giveaway route for retrieving a giveaway by ID, in addition to the authenticated server-management routes. This supports public-facing giveaway information without exposing administrative server APIs.

For lifecycle actions such as pause, resume, end, reroll, repair, and delete, read [Managing live giveaways](/giveaways/managing-live-giveaways).
