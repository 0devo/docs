# Community features

GiveawayX includes community-management tools outside its giveaway workflow. The active dashboard includes **Starboard**, **Sticky Messages**, and **Welcome & Goodbye**. The sidebar currently marks **Suggestions** and **Server Tag** as *Soon*.

## Starboard

Starboard republishes eligible Discord messages when they reach a reaction threshold. The dashboard has General, Behavior, Appearance, and Leaderboard tabs.

| Category | Supported controls |
| --- | --- |
| **General** | Enable/disable, pause/resume without erasing configuration, posting channel, emoji, threshold, embed colour, self-star behavior, channel blacklist, and multiple emoji/threshold targets. |
| **Eligibility filters** | Whitelisted channels, blacklisted roles, eligible-starrer roles, minimum account age, minimum server-join age, NSFW filtering, and attachment requirements. |
| **Behavior** | Per-user multi-reaction handling, auto-reacting, first-emoji behavior, bot-message handling, self-star cleanup, removal on unstar/delete, repost cooldown, and message-age limits. |
| **Restrictions** | Allow/deny lists for selected roles and channels. |
| **Message appearance** | Embed/plain format, author/title/description/source/image/thumbnail/footer/timestamp controls, source jump button, up to two extra URL buttons, attachment/video/file link handling, and custom text tokens. |
| **Leaderboard** | Read the Starboard leaderboard data returned by the server. |

Starboard text fields can use `{emoji}`, `{stars}`, `{author}`, `{channel}`, `{content}`, and `{link}` as contextual message values.

## Sticky Messages

A sticky message is reposted or refreshed based on its configured trigger. The underlying model supports text, title, image, thumbnail, footer, up to three URL buttons, reactions, role requirements, role pings, schedules, pause state, priority, content variants, webhooks, keyword matching, reaction triggers, and a free-form block builder.

| Capability | Details |
| --- | --- |
| **Repost cadence** | Trigger on messages, a chosen message count, 30 seconds, or one minute. |
| **Conditional triggers** | Match a keyword by contains, starts-with, ends-with, or exact mode; optionally delete the trigger message. |
| **Access and delivery** | Require a role, ping a role, use webhook mode with name/avatar overrides, and apply a per-user cooldown. |
| **Scheduling** | Enable a daily time window and selected days. |
| **Variants** | Rotate content sequentially or randomly. |
| **Builder** | Compose content, separator, section, image, and button blocks. |

## Welcome & Goodbye

The `/greet` command and dashboard welcome API manage welcome messages, goodbye messages, automatic roles, and DM greetings. The command supports add, remove, edit, enable, list, test, placeholder, auto-role, and DM-related subflows. Event messages can use configurable text, colour, media, ping options, and deletion timing.
