## /gcreate

Create a giveaway with a quick form

**Permission:** Manage Server, Administrator, or Giveaway Manager role

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/gcreate` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options.
  </Step>
  <Step title="Send it">
    A form opens: fill in the prize, duration and winners, optionally upload an image, then choose **Publish now** or **Customize in Studio**.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/gcreate
```
</CodeGroup>


<Info>
Opens a modal with a prize (required, up to 256 characters), duration (required), winner count (required, default: 1), and an optional prize image (PNG, JPG, GIF, or WEBP, up to 8 MB). You must choose what happens after submission: **Publish now**, using the server's appearance and default rules, or **Customize in Studio**, which opens the `/gstart` panel prefilled with these values. Inputs are validated before continuing. If there is an error, an ephemeral response appears with an **Edit and Retry** button that reopens the modal with your answers preserved. The accepted duration is 10 seconds to 90 days; winner-count and duration limits depend on the Premium plan. The command checks the current channel and the bot's permissions before opening the modal. The modal expires after 15 minutes. See [Creating giveaways](/giveaways/creating#gcreate-the-quick-form).
</Info>

## /gstart

Starts a giveaway with customizable options

**Permission:** Manage Server

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/gstart` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options. Optional: `duration`, `winners`, `prize`, `template`, `channel`, `image`, `thumbnail`, `required_roles`….
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/gstart
```
```text Fuller example
/gstart duration:1d winners:1 prize:Discord Nitro template:weekly-nitro
```
```text Prefix
g!gstart --duration=1d --winners=1 --prize=Discord Nitro
```
</CodeGroup>


| Option | Type | Required | Description | Notes |
| --- | --- | --- | --- | --- |
| `duration` | string | No | Duration of the giveaway (e.g. 1d, 2h, 30m) |  |
| `winners` | integer | No | Number of winners |  |
| `prize` | string | No | The prize being given away |  |
| `template` | string | No | Use a saved template |  |
| `channel` | channel | No | Channel where the giveaway will be hosted |  |
| `image` | attachment | No | Image for the giveaway |  |
| `thumbnail` | attachment | No | Thumbnail for the giveaway |  |
| `required_roles` | string | No | Roles required to participate |  |
| `requirement_bypass_roles` | string | No | Roles that bypass requirements |  |
| `blacklist_roles` | string | No | Roles blacklisted from participating |  |
| `winners_roles` | string | No | Roles given to winners |  |
| `description` | string | No | Description for the giveaway |  |
| `host` | user | No | User who is hosting the giveaway |  |
| `giveaway_create_message` | string | No | Custom message when giveaway is created |  |
| `joined_age` | integer | No | Minimum days the user must have been in the server |  |
| `account_age` | integer | No | Minimum age of the user's Discord account (days) |  |
| `required_messages` | integer | No | Number of messages required |  |
| `extra_entries` | string | No | Bonus entries for roles (e.g., @role 5) |  |
| `max_entries` | integer | No | Max extra entries a user can earn from voting | Range: 1 to 10 |
| `repeat` | integer | No | Number of times to repeat (Premium) | Range: 1 to no max |
| `sticky` | boolean | No | Auto-resend giveaway (Premium Tier 2+) |  |
| `required_official_tag` | boolean | No | Whether the user must have the official server tag |  |
| `required_level` | integer | No | Minimum level required to enter (leveling system) | Range: 1 to no max |
| `auto_claim` | boolean | No | Auto Claim & Reroll: winners claim with one button; unclaimed prizes auto-reroll |  |

<Info>
See [Creating giveaways](/giveaways/creating) for how each group of options works. Role list options accept role mentions or IDs. Values not provided fall back to the selected `template`, then to the server defaults.
</Info>

## /gdrop

Starts a drop giveaway — first to claim wins!

**Permission:** Manage Server

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/gdrop` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    Required: `prize`. Optional: `winners`, `duration`, `channel`, `image`, `thumbnail`, `countdown`, `blacklist_role`, `required_role`….
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/gdrop prize:Discord Nitro
```
```text Fuller example
/gdrop prize:Discord Nitro winners:1 duration:1d channel:#giveaways image:(attach a file)
```
</CodeGroup>


| Option | Type | Required | Description | Notes |
| --- | --- | --- | --- | --- |
| `prize` | string | Yes | The prize being given away |  |
| `winners` | integer | No | Number of winners (default: 1) | Range: 1 to 50 |
| `duration` | string | No | Duration (e.g. 1h, 30m, 1d) |  |
| `channel` | channel | No | Channel to host the drop in |  |
| `image` | attachment | No | Main image (images only) |  |
| `thumbnail` | attachment | No | Small thumbnail (images only) |  |
| `countdown` | integer | No | Countdown before drop (1–30 s) | Range: 1 to 30 |
| `blacklist_role` | role | No | Role that cannot participate |  |
| `required_role` | role | No | Role required to claim this drop |  |
| `message` | string | No | Additional message before the drop |  |

If `duration` is not specified, it defaults to one hour; if `channel` is not specified, the current channel is used. The winner limit is 10 on the free plan and 50 for Premium servers. The optional `countdown` is 1 to 30 seconds and displays a countdown in the channel before the drop is posted. Images may be JPEG/JPG, PNG, GIF, WEBP, BMP, or TIFF. `required_role` allows only members with the specified role to claim; members with `blacklist_role` are blocked, and `message` is shown before the drop. When the duration ends, claim buttons are disabled; claimants are announced as winners. If nobody enters, the giveaway ends with a no-participants status. See [Drops and last-to-type](/giveaways/drops).
