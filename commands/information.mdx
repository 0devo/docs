## `/help`

Displays the help center or usage information for a specific command. No special permission is required.

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/help` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options. Optional: `command`. Some options offer suggestions while you type; pick one from the list.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/help
```
```text Fuller example
/help command:gstart
```
</CodeGroup>


**Usage:** `/help [command]`

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `command` | string | No | The name of the command you want details about; supports autocomplete. |

- Without `command`, displays a help panel with a link to the commands page, the dashboard, the support server, and the bot invite link.
- With `command`, displays the command's description, usage, options, and examples, if it is listed in the help data.
- For slash commands, the help panel appears in the usual response. When using the prefix command, the panel is sent in a direct message and a ✅ confirmation reaction is added to the command message. If direct messages cannot be sent, the bot replies in the channel that it was unable to send the message.
- Autocomplete lists matching commands, with a maximum of 25 suggestions. This does not guarantee that every suggestion has a detailed entry in the help data.

**Example:** `/help command:ping`

## `/ping`

Checks the bot's responsiveness and connections, and displays runtime and system information. It requires no options or special permissions, and the implementation does not set a cooldown.

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/ping` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/ping
```
</CodeGroup>


**Usage:** `/ping`

A measurement indicator appears first, then the bot replaces it with a panel containing:

- WebSocket latency, the round-trip time for the command response, and the latency of a REST request to the Discord API; each is rated Excellent, Good, Average, or Poor. If REST latency cannot be measured, the value is `N/A`.
- Discord's status, obtained from the public status API; if it cannot be fetched, the status is `Unknown`.
- WebSocket connection status, bot uptime and connection time, shard ID and shard count, cluster ID, and REST API version.
- Memory usage (Heap and RSS) and Node.js version, along with the bot, shard, and cluster identities and the time.

If command execution fails, the bot attempts to display an error message containing the error details. The response does not show cache statistics, although they are collected during execution.

## `/invite`

Displays a public panel with three buttons: **Invite Bot** to open the bot's add-to-server link, **Support Server** for the support server, and **Vote on Top.gg** to vote. The panel includes the bot's image and name, along with the display time. It requires no options or special permissions, and has a 5-second cooldown.

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/invite` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/invite
```
</CodeGroup>


**Usage:** `/invite`

If an error occurs during processing, the bot attempts to send an error panel visible only to the user who invoked the command.
