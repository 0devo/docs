---
title: "Right-click actions"
description: "Run commands by right-clicking a member or a message."
icon: "computer-mouse"
---

Right-click (or long-press on mobile) a member or message, then choose **Apps**.

## On members

| Action | What it does |
| --- | --- |
| Avatar | Show their avatar. |
| User Info | Show information about them. |
| Rank | Show their rank card. |
| Give Rep | Give them a reputation point. |
| Change Nickname | Change their nickname. |
| Challenge to RPS | Challenge them to Rock Paper Scissors. |
| Challenge to XO | Challenge them to Tic-Tac-Toe. |

## On messages

| Action | What it does |
| --- | --- |
| Message Info | Show information about the message. |
| Translate Message | Translate it. See [Translate](/features/translate). |
| Steal Emoji | Copy an emoji from the message to your server. |

## On giveaway messages

<Info>
These need the same permission as the matching command. See [Permissions](/concepts/permissions).
</Info>

| Action | Same as |
| --- | --- |
| Reroll Giveaway | `/greroll` |
| Edit Giveaway | `/gedit` |
| Delete Giveaway | `/gdelete` |
| Pause Giveaway | `/gpause` |
| Resume Giveaway | `/gresume` |
| End Giveaway | `/gend` |
| Fix Giveaway | `/gfix` |
