Displays a public panel with three buttons: **Invite Bot** to open the bot's add-to-server link, **Support Server** for the support server, and **Vote on Top.gg** to vote. The panel includes the bot's image and name, along with the display time. It requires no options or special permissions, and has a 5-second cooldown.

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/invite` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/invite
```
</CodeGroup>


**Usage:** `/invite`

If an error occurs during processing, the bot attempts to send an error panel visible only to the user who invoked the command.
