## Purchasing Premium Now
Current purchases are made through the [plans page](https://giveawayx.lol/plans), not Patreon. Sign in to the website, choose **Silver** or **Diamond** and a monthly or annual billing cycle, then specify the number of servers and the servers where the bot is installed. After you review your order, the website redirects you to the payment processor’s secure checkout page. According to the website FAQ, Premium is automatically activated for the selected servers after payment is confirmed, with no activation code or manual step. Enter payment details only on the secure checkout page.

If you have a manual or legacy subscription, the FAQ says your current access continues until the end of its original term; use the website checkout when renewing or upgrading. Do not assume that the legacy Patreon commands below activate or sync with a website purchase: this integration is not verified by the source for these commands, and the bot’s status may differ from what the website displays.

## Admin and Developer Commands
The following two commands exist in the bot source, but are restricted to bot owners/developers by a `client.owners` check in their implementation. The `permission: Administrator` value in their definitions is not the actual developer restriction; non-owners cannot successfully use them.


### `/premium-add`
A developer command to manually add or renew Premium for a server. It requires the following options:

| Option | Required | Description |
| --- | --- | --- |
| `guild_id` | Yes | ID of the server to update. |
| `tier` | Yes | `1` for **Silver** or `2` for **Diamond**. |
| `duration` | Yes | A duration such as `1y`, `6M`, or `30d`; supported units are seconds `s`, minutes `m`, hours `h`, days `d`, approximate 30-day months `M`, and approximate 365-day years `y`. |
| `owner_id` | Yes | ID of the user recorded as the subscription owner. |
| `addon_slots` | No | Additional server bundle: `0`, `x2`, `x4`, `x6`, `x9`, or `x10`. |
| `addon_mode` | No | `set` to replace/set the total (default), or `add` to add slots to the current total. |

Manually activates Premium, applies add-on slots if requested, creates a PDF invoice, and attempts to send it to the recorded user. This is an internal command, not the website checkout, and it is not proof that payment was received.

### `/premium-removal guild_id:<server ID>`
A developer command to remove Premium from the specified server and restore its custom settings to their defaults. It requires only the `guild_id` option and removes the subscription by calling `deactivatePremium`. Although the Discord permission is defined as Administrator, the implementation allows only an ID present in `client.owners`.

## Compatibility Notes
The Patreon commands (`/premium-link` and `/premium-activate`) and manual admin tools (`/premium-add` and `/premium-removal`) operate on the bot’s current records according to their source, but the source does not establish integration with the website checkout or the website processor’s payment confirmations. Therefore, use the plans page for current purchases and check `/premium-info` after payment is confirmed; if the status does not match, contact support instead of trying to activate the order with a legacy Patreon command.
