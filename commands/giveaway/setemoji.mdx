Set a custom emoji for giveaway participation button (Premium Only)

**Permission:** Manage Server

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/setemoji` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    Required: `emoji`.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/setemoji emoji:🎁
```
</CodeGroup>


| Option | Type | Required | Description | Notes |
| --- | --- | --- | --- | --- |
| `emoji` | string | Yes | The emoji to use for giveaway buttons |  |

**Premium Tier 1 or higher.** Accepts a single Unicode emoji (including combined emoji sequences) or a custom emoji in `<:name:id>` or `<a:name:id>` format, up to 100 characters. Applies to entry buttons on new giveaways. Example: `/setemoji emoji:🎉`.
