Delete a giveaway

**Permission:** Manage Server · Server only

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/gdelete` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    Required: `giveaway_id`. Some options offer suggestions while you type; pick one from the list.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/gdelete giveaway_id:123456789012345678
```
```text Prefix
g!gdelete 123456789012345678
```
</CodeGroup>


| Option | Type | Required | Description | Notes |
| --- | --- | --- | --- | --- |
| `giveaway_id` | string | Yes | Select the giveaway to delete (or paste a message ID / link) | Autocomplete |

Server only. Also available as the **Delete Giveaway** message action.
