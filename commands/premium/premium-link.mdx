Creates a short code to link the current server to Patreon data; the code is valid for 30 minutes. It displays legacy instructions for matching the Discord account connected to Patreon or placing the code in the membership note. The command requires **Manage Server** according to its definition. This is a Patreon-specific legacy path, not a current purchase method, and the source does not establish that it links or activates a website purchase.

{/* usage */}
**How to use**

<Steps>
  <Step title="Open the command">
    Type `/premium-link` in a channel where the bot can see messages and pick it from the list.
  </Step>
  <Step title="Fill in the options">
    This command has no required options.
  </Step>
  <Step title="Send it">
    The bot replies with the result.
  </Step>
</Steps>

<CodeGroup>
```text Simplest form
/premium-link
```
</CodeGroup>
