Whenever a command asks for a duration (`/gstart`, `/gedit`, `/gdrop`, `/glast`, `/gschedule`) you write a number followed by a unit. You can combine units in one value.

## Units

| Unit | You can type |
| --- | --- |
| Seconds | `s`, `sec`, `secs`, `second`, `seconds` |
| Minutes | `m`, `min`, `mins`, `minute`, `minutes` |
| Hours | `h`, `hr`, `hrs`, `hour`, `hours` |
| Days | `d`, `day`, `days` |
| Weeks | `w`, `wk`, `wks`, `week`, `weeks` |

## Examples

<CodeGroup>
```text Simple
30m
2h
1d
```
```text Combined
1d12h
2h30m
1w2d
```
```text With spaces
1w 2d
3h 15m
```
</CodeGroup>

<Warning>
A number on its own, like `30`, is rejected because there is no unit. Always add one, for example `30m`.
</Warning>

<Note>
For long periods use days or weeks (`30d`, `4w`). Months are not a supported unit.
</Note>

## Commands with their own range

| Command | Range |
| --- | --- |
| `/glast` | 1 to 10 minutes |
| `/gdrop` countdown | 1 to 30 seconds |
| `/gschedule` start time | A duration from now, or a unix timestamp |
