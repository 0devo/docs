يُعاد نشر **الرسالة الثابتة** أثناء الدردشة لتبقى ظاهرة. وهي مثالية للقواعد والإعلانات وملاحظات «اقرأ هذا أولًا». يمكنك إدارتها باستخدام `/sticky` (يتطلب إذن **إدارة الرسائل**).

## إنشاء رسالة ثابتة

تُبنى الرسائل الثابتة من كتل، بحد أقصى **12 كتلة** لكل رسالة:

<Columns cols={3}>
  <Card title="نص" icon="font">نص منسّق.</Card>
  <Card title="فاصل" icon="minus">خط فاصل.</Card>
  <Card title="قسم" icon="table-columns">نص مع عنصر ملحق.</Card>
  <Card title="صورة" icon="image">صورة أو معرض صور.</Card>
  <Card title="زر" icon="rectangle-ad">زر قابل للنقر.</Card>
</Columns>

## وقت إعادة الإرسال

| الإعداد | السلوك |
| --- | --- |
| كل رسالة | بعد كل رسالة جديدة (الافتراضي) |
| كل 5 أو 10 رسائل | بعد هذا العدد من الرسائل |
| كل 30 ثانية | مرة واحدة كحد أقصى كل 30 ثانية |
| كل دقيقة | مرة واحدة كحد أقصى كل دقيقة |

أي خيار غير «كل رسالة» يتطلب <Badge color="blue">المستوى 1</Badge>.

## خيارات التوقيت

<Tabs>
  <Tab title="الاكتشاف">
    **فوري**، أو **مؤجّل**، وينتظر الخيار المؤجّل توقفًا مؤقتًا في المحادثة (5 ثوانٍ افتراضيًا) قبل إعادة النشر حتى لا يقاطع الدردشة السريعة.
  </Tab>
  <Tab title="التنظيف">
    اختر وقت حذف النسخة القديمة: عند بدء إرسال النسخة الجديدة، أو عند اكتمال إرسالها (الافتراضي)، أو بعد مهلة (5 ثوانٍ افتراضيًا).
  </Tab>
</Tabs>

## المشغّلات

بحسب مستواك، يمكن أيضًا أن تظهر الرسالة الثابتة عند ورود **كلمة مفتاحية**، أو وفق **جدول زمني**، أو حتى **عدد أقصى من المرات**، أو مع **فترة انتظار لكل مستخدم**، أو عندما **يتفاعل** شخص مع رسالة.
