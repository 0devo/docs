يرسل نظام الترحيب رسالة عندما **ينضم** شخص إلى خادمك أو **يغادره**. تصمم كل شيء من **لوحة الويب** (صفحة الترحيب والوداع) مع معاينة مباشرة. ويُضبط الانضمام والمغادرة كلٌّ على حدة، فيمكنك ترحيبًا دافئًا ووداعًا قصيرًا.

## ماذا يحدث عند الانضمام أو المغادرة

<Steps>
  <Step title="ينضم شخص أو يغادر">
    يتفاعل البوت فورًا.
  </Step>
  <Step title="تُملأ المتغيرات">
    تُخصَّص رسالتك ببيانات العضو (انظر الجدول أدناه).
  </Step>
  <Step title="تُرسل الرسالة">
    إلى القناة التي اخترتها، أو إلى العضو في **الخاص**، أو إلى الاثنين. وإذا تعذّر وصول رسالة الخاص يمكن للبوت الرجوع إلى القناة.
  </Step>
  <Step title="التنظيف والرتب">
    يمكن أن **تحذف الرسالة نفسها** بعد وقت محدد، وتُمنح الرتب التلقائية للأعضاء الجدد.
  </Step>
</Steps>

## خيارات الرسالة

| الإعداد | وظيفته |
| --- | --- |
| **التفعيل والقناة** | شغّل الترحيب (أو الوداع) واختر مكان إرساله. |
| **الصيغة** | رسالة **نصية** عادية أو **إيمبد**. |
| **إرسال خاص للعضو** | يرسل في الخاص. ويمكن **الرجوع إلى القناة** عند إغلاق الخاص. |
| **منشن العضو** | يشير إليه في رسالة القناة. |
| **الحذف بعد** | تُحذف الرسالة بعد 0 إلى 3600 ثانية (0 تبقيها). |
| **تجاهل البوتات** | لا تُرسل رسالة عندما يكون العضو الجديد بوتًا. مفعّل افتراضيًا. |

## المتغيرات

اكتبها في أي حقل نصي، وتُستبدل لكل عضو.

| المتغير | يصبح |
| --- | --- |
| `{user}` | إشارة إلى العضو |
| `{username}` | اسم المستخدم |
| `{server}` | اسم خادمك |
| `{memberCount}` | عدد الأعضاء الحالي |
| `{avatar}` | صورة العضو |
| `{serverIcon}` | أيقونة خادمك |
| `{accountAge}` | عمر حساب Discord، مثل «2 years» أو «5 days» |
| `{userCreatedDate}` | تاريخ إنشاء الحساب |
| `{timeInServer}` | مدة بقاء العضو في الخادم (مفيد في رسائل الوداع) |

<CodeGroup>
```text ترحيب
Welcome {user} to {server}! You are member #{memberCount}.
```
```text وداع
{username} has left after {timeInServer}. We'll miss you!
```
</CodeGroup>

<Note>
يعمل `{avatar}` و`{serverIcon}` أيضًا داخل حقول الصورة والصورة المصغرة في الإيمبد.
</Note>

## الإيمبد

يدعم ترحيب الإيمبد **اللون** والمؤلف والعنوان والوصف والصورة المصغرة والصورة والتذييل وحتى **10 حقول** وطابعًا زمنيًا. إذا لم تختر لونًا فاللون **الأخضر** للانضمام و**الأحمر** للمغادرة.

## بطاقات الصور

يستطيع البوت إنشاء **بطاقة صورة** مخصصة بصورة العضو وإرفاقها بالرسالة.

<Columns cols={4}>
  <Card title="كلاسيكي" icon="image" />
  <Card title="لافتة" icon="panorama" />
  <Card title="بسيط" icon="minus" />
  <Card title="إطار" icon="border-all" />

يمكنك اختيار لون الخلفية أو صورتها، وشفافية الطبقة، ولونًا مميزًا، ونصي العنوان والعنوان الفرعي، و**شكل** الصورة الرمزية (دائرة أو مربع أو سداسي) وحجمها وإطارها.

## الرتب التلقائية

امنح الأعضاء الجدد رتبًا لحظة انضمامهم، مع **قائمتين منفصلتين للبشر وللبوتات**.

<Warning>
حفاظًا على الأمان **لا يمنح البوت أبدًا رتبة تحمل صلاحية المسؤول (Administrator)** عبر الرتب التلقائية، حتى لو أضفتها. اختر رتبًا عادية.
</Warning>

## الحماية من الغارات

حدّد **حدًا أدنى لعمر الحساب** (من 0 إلى 365 يومًا). الحسابات الأحدث من ذلك تُعامل كمشبوهة. وفعّل **تخطي عند الحجب** لإرسال **أي رسالة ترحيب إطلاقًا** لتلك الحسابات، فلا ينال المهاجمون ترحيبًا.

<Info>
مع تفعيل **تجاهل البوتات** لا تحصل حسابات البوتات على رسالة، لكنها **تحصل على رتب البوتات التلقائية** التي حدّدتها.
</Info>

<Tip>
استخدم زر **رسالة الاختبار** في لوحة الويب لمعاينة الترحيب أو الوداع في قناتك قبل التفعيل.
</Tip>
