تنشر إشعارات منصات التواصل إعلانًا في قناة عندما يبدأ صانع محتوى تتابعه بثًّا مباشرًا أو ينشر فيديو. يمكنك تتبع عدة حسابات، لكل منها قناته ورسالته ورتبة التنبيه الخاصة به.

## المنصات المدعومة

<Columns cols={3}>
  <Card title="YouTube" icon="youtube">
    **فيديوهات** و**Shorts** و**بثوث مباشرة** جديدة. اختر أيًّا من الثلاثة تريد الإعلان عنه.
  </Card>
  <Card title="Twitch" icon="twitch">
    رسالة عندما يبدأ البثّاث **بثًّا مباشرًا**.
  </Card>
  <Card title="Kick" icon="video">
    رسالة عندما يبدأ البثّاث **بثًّا مباشرًا**.
  </Card>
</Columns>

## ما يمكنك ضبطه لكل حساب

| الإعداد | وظيفته |
| --- | --- |
| **القناة** | المكان الذي يُنشر فيه الإعلان. |
| **الحساب** | قناة YouTube، أو اسم مستخدم Twitch أو Kick. |
| **الرسالة** | نصّك الخاص. استخدم `{channel_name}` لـ YouTube و`{streamer}` لـ Twitch وKick. |
| **الرتبة المنشَنة** | منشن رتبة اختيارية مع كل إعلان. |
| **أنواع المحتوى** (YouTube) | أعلِن عن الفيديوهات وShorts والبثوث المباشرة كلٌّ على حدة. |
| **التفعيل** | أوقف حسابًا مؤقتًا دون حذفه. |

## الرسائل الافتراضية

<CodeGroup>
```text YouTube
🎥 New video from **{channel_name}**!
```
```text Twitch
🔴 **{streamer}** is now live on Twitch!
```
```text Kick
🟩 **{streamer}** is now live on Kick!
```
</CodeGroup>

<Tip>
امنح كل صانع محتوى رتبته الخاصة مثل `@Streams` ليختار الأعضاء الاشتراك في تنبيهات من يهمهم فقط.
</Tip>

<Note>
يتذكر البوت آخر بث أو فيديو أعلن عنه، فلا يصلك إشعاران عن المحتوى نفسه.
</Note>
