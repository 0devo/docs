---
title: "عضو لا يستطيع الدخول إلى السحب"
description: "اعرف أي شرط يمنعه."
icon: "user-xmark"
---

يخبر البوت العضو بشكل خاص بالشرط الذي فاته. الأسباب الشائعة:

| السبب | الحل |
| --- | --- |
| رتبة ناقصة | امنحه الرتبة، أو أضف رتبة تجاوز |
| الحساب أو العضوية جديدان | انتظر، أو خفّض الحد الأدنى للعمر |
| رسائل أو مستوى غير كافٍ | شارك أكثر، أو خفّض الشرط |
| لا يدعم بالبوست | ادعم الخادم، أو احذف شرط البوست |
| لم يجتز التحقق | أكمل الفحص |
| فترة انتظار الفائزين | انتظر انتهاءها |

راجع [الدخول إلى سحب](/ar/giveaways/participating) للقائمة الكاملة.
