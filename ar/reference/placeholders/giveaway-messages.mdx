---
title: "متغيرات رسائل السحوبات"
description: "متغيرات الرسائل الخاصة للسحوبات وإعلان الفائزين وسلاسل الفائزين وإيمبد السحب."
icon: "gift"
---

يُعدَّل نص السحوبات من `/settings` (راجع [إعدادات الخادم](/ar/giveaways/settings)). وتعتمد المتغيرات المتاحة على **الرسالة** التي تعدّلها.

<Tabs>
  <Tab title="رسائل الفائز والمضيف الخاصة" icon="envelope">
    | المتغير | يصبح |
    | --- | --- |
    | `{prize}` | جائزة السحب |
    | `{server}` | اسم خادمك |
    | `{winners_count}` | عدد الفائزين المختارين |
    | `{winners_list}` | الفائزون كإشارات |
    | `{timestamp}` | وقت الانتهاء كرقم. اكتبه داخل وسم الوقت في Discord مثل `<t:{timestamp}:F>` لعرض تاريخ منسّق |

    ```text مثال رسالة المضيف
    🎁 Prize: {prize}
    🏆 Winners ({winners_count}): {winners_list}
    📅 Ended: <t:{timestamp}:F>
    ```
  </Tab>
  <Tab title="إعلان الفائزين" icon="trophy">
    | المتغير | يصبح |
    | --- | --- |
    | `{prize}` | جائزة السحب |
    | `{winners_list}` | الفائزون كإشارات |
    | `{winners_count}` | عدد الفائزين |
    | `{host}` | المضيف |
    | `{server}` | اسم خادمك |
    | `{date}` | التاريخ |

    ```text مثال
    Congratulations {winners_list}! You won **{prize}**!
    ```
  </Tab>
  <Tab title="سلسلة الفائزين" icon="comments">
    تُستخدم في **اسم السلسلة** و**رسالتها** معًا.

    | المتغير | يصبح |
    | --- | --- |
    | `{prize}` | جائزة السحب |
    | `{prize_short}` | جائزة مختصرة ليتسع الاسم الطويل في عنوان السلسلة |
    | `{host}` | المضيف |
    | `{channel}` | قناة السحب |
    | `{date}` | التاريخ |
    | `{winners_list}` | الفائزون |

    يستخدم اسم السلسلة الافتراضي `{gift}` (إيموجي هدية) و`{prize_short}` و`{channel}` و`{date}` مفصولة بنقاط.
  </Tab>
  <Tab title="قالب إيمبد السحب" icon="rectangle-list">
    يُستخدم عند تخصيص تخطيط رسالة السحب.

    | المتغير | يصبح |
    | --- | --- |
    | `{prize}` | الجائزة |
    | `{host}` | المضيف |
    | `{end_time}` | موعد انتهاء السحب |
    | `{winners_count}` | عدد الفائزين |
    | `{description}` | وصف السحب |
    | `{enter_button}` | زر الدخول |
    | `{info_rows}` و`{extra}` و`{bullet}` | لبنات يستخدمها التخطيط الافتراضي لقائمة التفاصيل والشروط الإضافية ورمز النقطة |
    | `{lbl_ends}` و`{lbl_host}` و`{lbl_winners}` | التسميات المترجمة لـ «ينتهي» و«المضيف» و«الفائزون» |
  </Tab>
</Tabs>

<Tip>
افتح الرسالة في `/settings` واستخدم زر **المعاينة** للتحقق من ظهور المتغيرات قبل الحفظ.
</Tip>
