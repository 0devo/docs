title: "مسرد المصطلحات"
description: "معاني مبسّطة للمصطلحات المستخدمة في هذه الوثائق."
icon: "book"
---

مرّر المؤشر فوق أي مصطلح ذي خط منقّط في الوثائق لعرض تعريف مختصر له. تسرد هذه الصفحة جميع المصطلحات.

| المصطلح | المعنى |
| --- | --- |
| <Tooltip tip="سحب تُمنح فيه الجائزة عشوائيًا عند انتهاء المؤقّت.">السحب</Tooltip> | فعالية جوائز يشارك فيها الأعضاء ويُختار الفائزون من بينهم عشوائيًا. |
| <Tooltip tip="سحب يفوز فيه أول من يطالب بالجوائز فورًا.">السحب الفوري</Tooltip> | سحب فوري: يفوز أول من يطالب بالجائزة. |
| <Tooltip tip="اللوحة التفاعلية التي تراجع فيها السحب وتعدّله قبل نشره.">الاستوديو</Tooltip> | اللوحة المستخدمة لإعداد السحب مع معاينة مباشرة. |
| <Tooltip tip="إعدادات سحب محفوظة يمكنك إعادة استخدامها.">القالب</Tooltip> | مجموعة إعدادات سحب محفوظة باسم. |
| <Tooltip tip="فرص إضافية للفوز إلى جانب فرصة المشاركة العادية الواحدة.">المشاركات الإضافية</Tooltip> | مشاركات إضافية مقابل الرتب والمستويات والتصويت وغير ذلك. |
| <Tooltip tip="إعادة اختيار الفائزين عشوائيًا بعد انتهاء السحب.">إعادة السحب</Tooltip> | اختيار فائزين بدلاء أو جدد. |
| <Tooltip tip="تجميد العدّ التنازلي دون فقدان الوقت المتبقي.">الإيقاف المؤقت</Tooltip> | يوقف المؤقّت؛ ويُستكمل الوقت المتبقي عند الاستئناف. |
| <Tooltip tip="يؤكّد الأعضاء استلام الجائزة بزر واحد؛ وتُعاد قرعة الجوائز التي لم يُطالب بها.">المطالبة التلقائية</Tooltip> | مهلة تلقائية للمطالبة بالجوائز مع إعادة السحب. |
| <Tooltip tip="رتب يُسمح لها بتشغيل أوامر السحب دون إذن إدارة الخادم.">رتبة مدير السحوبات</Tooltip> | رتبة تثق بها لإدارة السحوبات. |
| <Tooltip tip="الشارة الخاصة بالخادم التي يمكن للأعضاء عرضها بجانب أسمائهم.">وسم الخادم الرسمي</Tooltip> | وسم يعرضه الأعضاء في ملفاتهم الشخصية لتمثيل خادمك. |
| <Tooltip tip="نقاط خبرة تُكتسب بالدردشة والتواجد في القنوات الصوتية.">XP</Tooltip> | نقاط ترفع مستوى العضو. |
| <Tooltip tip="خطة مدفوعة تُطبّق على خادم واحد.">فئة Premium</Tooltip> | الفئة 1 أو 2 أو 3 من Premium لخادم. |
| <Tooltip tip="نص يُرسل قبل الأمر، مثل g!">البادئة</Tooltip> | ما تكتبه قبل الأمر النصّي. القيمة الافتراضية هي `g!`. |
| <Tooltip tip="رسالة يُعاد نشرها لتبقى قرب أسفل القناة.">الرسالة اللاصقة</Tooltip> | رسالة تستمر في الظهور مجددًا أسفل القناة. |
| <Tooltip tip="قناة يُعاد فيها نشر الرسائل الشائعة.">لوحة النجوم</Tooltip> | قناة لعرض الرسائل التي تحصل على عدد كافٍ من التفاعلات. |
