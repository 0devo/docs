## الإعدادات الافتراضية

| الإعداد | القيمة الافتراضية |
| --- | --- |
| البادئة | `g!` |
| لون الزر | أساسي |
| طريقة عرض المضيف | إشارة (أو اسم المستخدم، أو مخفي) |
| نوع المشاركة | زر |
| المدة الافتراضية | ساعة واحدة |
| الرسائل الخاصة للفائزين والرسائل الخاصة للمضيف | مفعّلة |
| سلسلة محادثة الفائزين | معطّلة |
| ظهور سلسلة محادثة الفائزين | عامة |
| اختبار التحقق عند المشاركة | معطّل |
| فترة الانتظار بين مرات الفوز | معطّلة (0 دقيقة) |
| المنطقة الزمنية | UTC |

## أوامر سريعة

| الأمر | وظيفته |
| --- | --- |
| `/setcolor` | تعيين لون مخصص بالنظام الست عشري للرسائل المضمّنة للسحوبات، مثل `#ff0000`. <Badge color="blue">Premium</Badge> |
| `/setemoji` | تعيين رمز تعبيري مخصص لزر المشاركة. <Badge color="blue">Premium</Badge> |
| `/setlang` | تغيير لغة البوت في الخادم. راجع [اللغة](/ar/features/language). |

## رتب مدير السحوبات

يمكن للرتب المدرجة ضمن **رتب مدير السحوبات** إدارة السحوبات دون إذن إدارة الخادم. راجع [الأذونات](/ar/concepts/permissions).
