يحفظ **القالب** إعدادات السحب تحت اسم محدد. ابدأ النوع نفسه من السحب مجددًا باستخدام `/gstart template:<name>` أو `/gschedule create template:<name>`. أي قيمة تدخلها في الأمر تتجاوز القيمة المحفوظة في القالب.

## ما يحفظه القالب

<Columns cols={2}>
  <Card title="الأساسيات" icon="gift">الاسم، والجائزة، والوصف، والمدة، والفائزون، والقناة.</Card>
  <Card title="الوسائط" icon="image">الصورة والصورة المصغرة.</Card>
  <Card title="الأدوار" icon="user-tag">الأدوار المطلوبة، وأدوار التجاوز، والقائمة السوداء، والفائزين، مع أوضاعها.</Card>
  <Card title="المتطلبات" icon="shield-check">المدة منذ الانضمام، وعمر الحساب، والدعوات، والرسائل، والمستوى، والوسم الرسمي.</Card>
  <Card title="التحقق" icon="camera">إعدادات التحقق بلقطة شاشة.</Card>
  <Card title="فرص المشاركة" icon="ticket">فرص المشاركة الإضافية ونوع المشاركة (زر أو تفاعل).</Card>
</Columns>

كما يحفظ خيارات مثل التكرار، والتثبيت، وإعدادات المطالبة التلقائية، ورسالة الإنشاء المخصصة.

## الأوامر

| الأمر | وظيفته |
| --- | --- |
| `/gtemplate create` | إنشاء قالب جديد. |
| `/gtemplate edit basic` | تعديل الاسم، والجائزة، والمدة، والفائزين، والقناة، والوصف. |
| `/gtemplate edit requirements` | تعديل متطلبات الأدوار، والعمر، والدعوات، والرسائل، والمستوى. |
| `/gtemplate edit entries` | تعديل فرص المشاركة الإضافية وفرص المشاركة بالتصويت. |
| `/gtemplate edit media` | تعديل الصورة والصورة المصغرة. |
| `/gtemplate list` | عرض جميع القوالب. |
| `/gtemplate view` | عرض التفاصيل الكاملة لقالب واحد. |
| `/gtemplate preview` | عرض معاينة مرئية للسحب. |
| `/gtemplate duplicate` | نسخ قالب باسم جديد. |
| `/gtemplate delete` | حذف قالب (يطلب التأكيد). |
| `/gtemplate export` | تنزيل قالب كملف قابل للمشاركة. |
| `/gtemplate import` | تحميل قالب من ملف مُصدَّر. |

<Tip>
استخدم **التصدير** و**الاستيراد** لنقل قالب بين خوادمك، أو للاحتفاظ بنسخة احتياطية.
</Tip>

## استخدام قالب

<CodeGroup>
```text Use as is
/gstart template:weekly-nitro
```
```text Override some values
/gstart template:weekly-nitro winners:3 duration:2d
```
```text Schedule it
/gschedule create template:weekly-nitro start_time:1d
```
</CodeGroup>

يحتفظ المثال الثاني بكل إعدادات القالب، لكنه يغيّر عدد الفائزين والمدة. إذا لم يتضمن القالب جائزة أو مدة، فسيخبرك البوت بالقيمة الناقصة.
