**الاستوديو (Studio)** هو اللوحة التفاعلية التي تفتح عند اختيار **التخصيص في الاستوديو** من `/gcreate`، أو عند تشغيل `/gstart`. وهو أيضًا أساس `/gedit` و`/gschedule`. تبني السحب خطوة بخطوة وترى **معاينة مباشرة**، ولا تنشره إلا حين ترضى عنه.

<Tip>
لست مضطرًا إلى ملء كل شيء. يتتبع الاستوديو عدد **الأساسيات** المكتملة (مثل «2/3») ويخبرك عندما يصبح السحب **جاهزًا للنشر**.
</Tip>

  </Card>
  <Card title="المراجعة والنشر (Review and Publish)" icon="paper-plane">

  </Card>
  <Card title="القوالب" icon="copy">

<Note>
زر **Cancel** يتجاهل المسودة. ويعرض الاستوديو كذلك زر **AI Giveaway** مكتوبًا عليه **قريبًا**.
</Note>

## إعدادات السحب

افتح **Giveaway Settings** للوصول إلى الفئات. لكل فئة قائمة تختار منها الإعداد المراد تغييره، وسطر حالة يوضح مدى اكتمالها. يمكنك فتحها بأي ترتيب.

<Tabs>
  <Tab title="الإعداد الأساسي" icon="gift">
    الجائزة والمدة والفائزون والمضيف والقناة والوصف والوسائط.

    | الإعداد | وظيفته |
    | --- | --- |
    | **الجائزة** | ما تقدمه في السحب. |
    | **المدة** | مدة السحب. الصيغة: `1d` أو `2h` أو `30m`. |
    | **الفائزون** | عدد الفائزين. |
    | **المضيف** | من يستضيف، وهل يُمنشَن المضيف، وهل يُعرض أو يُخفى. |
    | **القناة** | مكان النشر. اتركها فارغة لاستخدام القناة الحالية. |
    | **الوصف** | نص يظهر داخل السحب. |
    | **الصورة والصورة المصغرة** | صور السحب. اتركها فارغة للإبقاء على الحالية. |
  </Tab>
  <Tab title="شروط الدخول" icon="shield-check">
    الرتب المطلوبة والنشاط وعمر الحساب وعمر العضوية في الخادم والوسم الرسمي وعدد البوستات ومدتها.

    | الإعداد | وظيفته |
    | --- | --- |
    | **الرتب المطلوبة** | رتب يجب أن يملكها العضو. اختر **أي واحدة** أو **كلها** أو **حدًا أدنى** من العدد، وأضف قائمة الرتب أو عدّلها، وحدّد اختياريًا **مدة الاحتفاظ** بالدقائق. |
    | **الرسائل المطلوبة** | عدد الرسائل التي يجب أن يكون العضو قد أرسلها (0 يعطّله). يمكنك تضييقه بـ **نافذة زمنية**، وبـ **أي القنوات** تُحتسب (كلها أو قائمة)، وبـ **رسائل من** تُحتسب (الجميع أو رتب معينة). |
    | **المستوى المطلوب** | حد أدنى لمستوى الخادم (0 يعطّله). |
    | **عمر العضوية الأدنى** | عدد الأيام في الخادم (0 يعطّله). |
    | **عمر الحساب الأدنى** | عدد الأيام منذ إنشاء الحساب (0 يعطّله). |
    | **الوسم الرسمي مطلوب** | يدخل فقط من يعرض وسم الخادم. |
    | **عدد البوستات** | الحد الأدنى لعدد مرات دعم العضو للخادم (0 يعطّله). |
    | **مدة البوست** | عدد الأيام التي استمر فيها العضو بالدعم دون انقطاع (0 يعطّله). |
  </Tab>
  <Tab title="المكافآت والمشاركات الإضافية" icon="ticket">
    المشاركات الإضافية وحدودها ورتب الفائزين التلقائية.

    | الإعداد | وظيفته |
    | --- | --- |
    | **مشاركات إضافية** | مشاركات إضافية حسب الرتبة أو المستوى أو الخبرة أو التتابع أو وسم الخادم. أضف قواعد بمضاعِف أو بنطاق عشوائي، واختر هل **تتراكم** المكافآت. |
    | **الحد الأقصى لمشاركات التصويت** | أقصى عدد من المشاركات الإضافية يكسبه العضو بالتصويت. 0 يعني غير محدود. |
    | **رتب الفائزين** | رتب تُمنح للفائزين، مع مكافآت اختيارية من الخبرة أو المستويات، وتأخير، ومدة مؤقتة، وإزالة من الفائزين السابقين. |
  </Tab>
  <Tab title="التحكم في الوصول" icon="lock">
    من يُمنع ومن يُسمح له بالتجاوز.

    | الإعداد | وظيفته |
    | --- | --- |
    | **الرتب المحظورة** | رتب ممنوعة من الدخول. اختر أي واحدة أو كلها أو حدًا أدنى أو حدًا أقصى للعدد. |
    | **رتب التجاوز** | رتب تتخطى الشروط. يمكن أن تتجاوز كل قاعدة **كل الشروط** أو **الشروط التي تحددها فقط**، وأن تجمع كل الرتب المطابقة أو تستخدم **أعلى** رتبة فقط. |
    | **تجاوز فترة انتظار الفائزين** | يمنع الفائزين الجدد في **أي** سحب. اتركه فارغًا لاتباع الخادم، أو 0 لإيقافه في هذا السحب. |
  </Tab>
  <Tab title="متقدم" icon="sliders">
    طريقة الدخول والتكرار والوضع اللاصق والرسائل المخصصة.

    | الإعداد | وظيفته |
    | --- | --- |
    | **نوع الدخول** | **زر** أو **تفاعل**. لا يمكن الجمع بين الدخول بالتفاعل واختبار التحقق. |
    | **إيموجي التفاعل** | يُستخدم مع الدخول بالتفاعل فقط. والإيموجي المخصص يحتاج Premium. |
    | **تكرار السحب** | عدد مرات التكرار والانتظار قبل إعادة التشغيل. Premium. |
    | **لاصق** | يعيد إرسال السحب عند حديث الأعضاء. Premium المستوى 2. |
    | **المطالبة التلقائية وإعادة السحب** | زر **Claim** مشترك واحد. حدد مهلة المطالبة وأقصى عدد لإعادة السحب لكل جائزة. |
    | **رسالة الإنشاء** | رسالة منفصلة تُرسل عند بدء السحب. |
    | **المنشن** | رتب تُنبَّه عند النشر، مع `@here` اختياريًا. |
    | **رسالة التنبيه التلقائي** | نص اختياري يُرسل مع التنبيهات المتكررة. راجع [التنبيه التلقائي](/ar/giveaways/auto-ping). |
  </Tab>
</Tabs>

## المظهر (لهذا السحب فقط)

يغيّر **المظهر (Appearance)** شكل هذا السحب وسلوكه دون المساس بإعدادات الخادم الافتراضية. تعرض الشاشة الرئيسية عدد المجالات التي غيّرتها، أو «استخدام إعدادات الخادم».

<AccordionGroup>
  <Accordion title="زر الدخول" icon="hand-pointer">
    **نص زر الانضمام** و**لونه** و**نص زر المشاركين**، وهل زر المشاركين **ظاهر أم مخفي**.
  </Accordion>
  <Accordion title="التحقق عند الدخول" icon="robot">
    **اشتراط اختبار التحقق**: اتباع إعداد الخادم، أو تشغيله دائمًا، أو إيقافه دائمًا. **الصعوبة**: سهل (4 أرقام)، أو متوسط (5 خانات، الافتراضي)، أو صعب (7 خانات).
  </Accordion>
  <Accordion title="الحماية من الغارات" icon="shield-halved">
    **الحد الأدنى لاكتمال الملف الشخصي**: متوقف، أو جزئي (صورة مخصصة **أو** لافتة أو لون)، أو كامل (الاثنان). **كشف أسماء المستخدمين المشبوهة**: متوقف، أو منخفض (يحظر نمطًا تكرر في 3 حسابات جديدة أو أكثر)، أو متوسط (يحظر أيضًا مزيج الخلو من حروف العلة مع سلسلة أرقام طويلة)، أو مرتفع (يحظر عند أي مؤشر مشبوه واحد، مع إنذارات خاطئة أكثر).
  </Accordion>
  <Accordion title="سلسلة محادثات الفائزين" icon="comments">
    اتبع إعداد الخادم، أو **فعّل** السلسلة أو **عطّلها** لهذا السحب، واختر نوعها (عامة أو خاصة). راجع [الفائزون والمطالبات](/ar/giveaways/winners-and-claims).
  </Accordion>
  <Accordion title="المزيد" icon="ellipsis">
    يمكن أيضًا تغيير لون الإيمبد وقالبه ومنشن المضيف ورسائل الفائز والمضيف الخاصة لسحب واحد. ولكل منها خيار **إعادة ضبط** للعودة إلى إعدادات الخادم.
  </Accordion>
</AccordionGroup>

## النشر

<Steps>
  <Step title="اضغط «Review and Publish»">
    ترى **معاينة** للسحب كما سيراه الأعضاء تمامًا.
  </Step>
  <Step title="راجع التفاصيل">
    صحّح أي شيء بأزرار **الرجوع**. لكل شاشة فرعية طريق للعودة إلى الاستوديو.
  </Step>
  <Step title="انشر">
    أكّد فينطلق السحب. وللبدء لاحقًا استخدم **Schedule**. راجع [الجدولة](/ar/giveaways/scheduling).
  </Step>
</Steps>

<Warning>
لا تُطبَّق تغييرات الاستوديو إلا عند النشر أو الحفظ. وإذا ضغطت **Cancel** تُتجاهل المسودة.
</Warning>
