إنشاء سحب مجدول

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gschedule create` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    لا يحتوي هذا الأمر على خيارات إلزامية. الخيارات الاختيارية: `start_time`, `prize`, `duration`, `winners`, `channel`, `template`, `image`, `thumbnail`….
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gschedule create
```
```text مثال أوسع
/gschedule create start_time:1d prize:Discord Nitro duration:1d winners:1
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `start_time` | نص | لا | وقت البدء (مثل 1d، 2h30m، أو طابع زمني بنظام Unix) |  |
| `prize` | نص | لا | الجائزة |  |
| `duration` | نص | لا | المدة بعد البدء (مثل 1d، 2h) |  |
| `winners` | عدد صحيح | لا | عدد الفائزين |  |
| `channel` | قناة | لا | القناة |  |
| `template` | نص | لا | استخدام قالب محفوظ |  |
| `image` | مرفق | لا | الصورة |  |
| `thumbnail` | مرفق | لا | الصورة المصغرة |  |
| `required_roles` | نص | لا | الرتب المطلوبة |  |
| `requirement_bypass_roles` | نص | لا | رتب تجاوز المتطلبات |  |
| `blacklist_roles` | نص | لا | الرتب المحظورة |  |
| `winners_roles` | نص | لا | الرتب الممنوحة للفائزين |  |
| `description` | نص | لا | الوصف |  |
| `host` | مستخدم | لا | المستخدم المضيف |  |
| `giveaway_create_message` | نص | لا | رسالة بدء مخصصة |  |
| `joined_age` | عدد صحيح | لا | الحد الأدنى للأيام في الخادم |  |
| `account_age` | عدد صحيح | لا | الحد الأدنى لعمر الحساب (بالأيام) |  |
| `required_messages` | عدد صحيح | لا | الحد الأدنى للرسائل المطلوبة |  |
| `extra_entries` | نص | لا | فرص مشاركة إضافية (مثل @role 5) |  |
| `max_entries` | عدد صحيح | لا | الحد الأقصى لفرص المشاركة الإضافية من التصويت | النطاق: من 1 إلى 10 |
| `repeat` | عدد صحيح | لا | عدد مرات التكرار بعد بدء السحب (Premium) | النطاق: من 1 دون حد أقصى |
| `sticky` | قيمة منطقية | لا | إعادة الإرسال التلقائي (Premium من المستوى 2 فأعلى) |  |
| `required_official_tag` | قيمة منطقية | لا | اشتراط الوسم الرسمي |  |
| `required_level` | عدد صحيح | لا | الحد الأدنى للمستوى المطلوب | النطاق: من 1 دون حد أقصى |
