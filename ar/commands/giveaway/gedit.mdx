تعديل سحب نشط أو مجدول

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gedit` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    الخيارات الإلزامية: `giveaway_id`. الخيارات الاختيارية: `prize`, `duration`, `winners`, `image`, `thumbnail`, `required_role`, `requirement_bypass_role`, `blacklist_role`…. تعرض بعض الخيارات اقتراحات أثناء الكتابة؛ اختر منها.
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gedit giveaway_id:123456789012345678
```
```text مثال أوسع
/gedit giveaway_id:123456789012345678 prize:Discord Nitro duration:1d winners:1 image:(attach a file)
```
```text بالبادئة
g!gedit 123456789012345678
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `giveaway_id` | نص | نعم | اختيار السحب المراد تعديله | إكمال تلقائي |
| `prize` | نص | لا | الجائزة المقدمة في السحب |  |
| `duration` | نص | لا | مدة جديدة بدءًا من الآن (مثل 1d، 2h، 30m) |  |
| `winners` | عدد صحيح | لا | عدد الفائزين |  |
| `image` | مرفق | لا | صورة للسحب |  |
| `thumbnail` | مرفق | لا | صورة مصغرة للسحب |  |
| `required_role` | رتبة | لا | الرتبة المطلوبة للمشاركة |  |
| `requirement_bypass_role` | رتبة | لا | رتبة تتجاوز المتطلبات |  |
| `blacklist_role` | رتبة | لا | رتبة محظورة من المشاركة |  |
| `winners_role` | رتبة | لا | الرتبة الممنوحة للفائزين |  |
| `description` | نص | لا | وصف السحب |  |
| `host` | مستخدم | لا | المستخدم الذي يستضيف السحب |  |
| `giveaway_create_message` | نص | لا | رسالة مخصصة تظهر عند إنشاء السحب |  |
| `joined_age` | عدد صحيح | لا | الحد الأدنى لعدد الأيام التي يجب أن يكون المستخدم قد أمضاها في الخادم |  |
| `account_age` | عدد صحيح | لا | الحد الأدنى لعمر حساب المستخدم في Discord (بالأيام) |  |
| `extra_entries` | نص | لا | فرص مشاركة إضافية للرتب (مثل @role 5 @role2 7) |  |
| `max_entries` | عدد صحيح | لا | الحد الأقصى لفرص المشاركة الإضافية التي يمكن للمستخدم كسبها من التصويت (0 = غير محدود) | النطاق: من 0 إلى 10 |
| `repeat` | عدد صحيح | لا | عدد مرات التكرار (Premium) | النطاق: من 1 دون حد أقصى |
| `sticky` | قيمة منطقية | لا | إعادة إرسال السحب تلقائيًا (Premium من المستوى 2 فأعلى) |  |

راجع [إدارة السحوبات](/ar/giveaways/managing#gedit-edit-a-giveaway). لا يمكن تعديل السحوبات المنتهية.
