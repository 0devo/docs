إنشاء قالب سحب جديد

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gtemplate create` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    الخيارات الإلزامية: `name`. الخيارات الاختيارية: `prize`, `duration`, `winners`, `channel`, `description`, `entry_type`, `reaction_emoji`, `required_roles`….
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gtemplate create name:weekly-nitro
```
```text مثال أوسع
/gtemplate create name:weekly-nitro prize:Discord Nitro duration:1d winners:1 channel:#giveaways
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `name` | نص | نعم | اسم القالب (فريد) |  |
| `prize` | نص | لا | الجائزة الافتراضية |  |
| `duration` | نص | لا | المدة الافتراضية (مثل 1d، 2h، 30m) |  |
| `winners` | عدد صحيح | لا | العدد الافتراضي للفائزين | النطاق: من 1 دون حد أقصى |
| `channel` | قناة | لا | القناة الافتراضية |  |
| `description` | نص | لا | الوصف الافتراضي |  |
| `entry_type` | نص | لا | طريقة المشاركة | الخيارات: `button`، `reaction` |
| `reaction_emoji` | نص | لا | الرمز التعبيري لوضع المشاركة بالتفاعل |  |
| `required_roles` | نص | لا | الرتب المطلوبة للمشاركة |  |
| `requirement_bypass_roles` | نص | لا | الرتب التي تتجاوز المتطلبات |  |
| `winners_roles` | نص | لا | الرتب الممنوحة للفائزين |  |
| `blacklist_roles` | نص | لا | الرتب المحظورة من المشاركة |  |
| `joined_age` | عدد صحيح | لا | الحد الأدنى للأيام في الخادم | النطاق: من 1 دون حد أقصى |
| `account_age` | عدد صحيح | لا | الحد الأدنى لعمر حساب Discord (بالأيام) | النطاق: من 1 دون حد أقصى |
| `required_messages` | عدد صحيح | لا | الحد الأدنى للرسائل المطلوبة | النطاق: من 1 دون حد أقصى |
| `required_invites` | عدد صحيح | لا | الحد الأدنى للدعوات المطلوبة | النطاق: من 1 دون حد أقصى |
| `required_level` | عدد صحيح | لا | الحد الأدنى للمستوى المطلوب | النطاق: من 1 دون حد أقصى |
| `required_official_tag` | قيمة منطقية | لا | اشتراط وسم الخادم الرسمي |  |
| `extra_entries` | نص | لا | فرص مشاركة إضافية للرتب (مثل @role 5) |  |
| `max_entries` | عدد صحيح | لا | الحد الأقصى لفرص المشاركة الإضافية من التصويت | النطاق: من 1 إلى 10 |
| `giveaway_create_message` | نص | لا | رسالة مخصصة تُرسل عند البدء |  |
| `image` | مرفق | لا | صورة الجائزة |  |
| `thumbnail` | مرفق | لا | الصورة المصغرة |  |
| `repeat` | عدد صحيح | لا | عدد مرات التكرار (Premium) | النطاق: من 1 دون حد أقصى |
| `sticky` | قيمة منطقية | لا | سحب يُعاد إرساله تلقائيًا (Premium من المستوى 2 فأعلى) |  |
