تتطلب أوامر إدارة السحوبات صلاحية **إدارة الخادم** أو **المسؤول** أو **رتبة مدير السحوبات**. راجع [الصلاحيات](/ar/concepts/permissions).

## /gcreate

إنشاء سحب باستخدام نموذج سريع

**الصلاحية:** إدارة الخادم أو المسؤول أو رتبة مدير السحوبات

<Info>
يفتح نموذجًا (نافذة منبثقة) يتضمن الجائزة (مطلوبة، حتى 256 حرفًا)، والمدة (مطلوبة)، وعدد الفائزين (مطلوب، افتراضيًا 1)، وصورة جائزة اختيارية (PNG أو JPG أو GIF أو WEBP، حتى 8 ميغابايت)، وخيارًا مطلوبًا لما يحدث بعد الإرسال: **النشر الآن** باستخدام مظهر الخادم وقواعده الافتراضية، أو **التخصيص في الاستوديو** لفتح لوحة `/gstart` معبأة بالقيم. تُفحص المدخلات قبل المتابعة؛ وعند الخطأ تظهر استجابة خاصة مع زر **تعديل وإعادة المحاولة** يعيد فتح النموذج مع الاحتفاظ بالإجابات. المدة المقبولة من 10 ثوانٍ إلى 90 يومًا، وتخضع حدود الفائزين والمدة لخطة Premium. يفحص الأمر القناة الحالية وصلاحيات البوت قبل فتح النموذج، وتنتهي صلاحية النموذج بعد 15 دقيقة. راجع [إنشاء السحوبات](/ar/giveaways/creating#gcreate-the-quick-form).
</Info>

## /gdrop

بدء سحب سريع — أول من يطالب بالجائزة يفوز!

**الصلاحية:** إدارة الخادم

| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `prize` | نص | نعم | الجائزة المقدمة في السحب |  |
| `winners` | عدد صحيح | لا | عدد الفائزين (الافتراضي: 1) | النطاق: من 1 إلى 50 |
| `duration` | نص | لا | المدة (مثل 1h، 30m، 1d) |  |
| `channel` | قناة | لا | القناة التي سيُقام فيها السحب السريع |  |
| `image` | مرفق | لا | الصورة الرئيسية (صور فقط) |  |
| `thumbnail` | مرفق | لا | صورة مصغرة صغيرة (صور فقط) |  |
| `countdown` | عدد صحيح | لا | العد التنازلي قبل السحب السريع (1–30 ثانية) | النطاق: من 1 إلى 30 |
| `blacklist_role` | رتبة | لا | رتبة لا يمكنها المشاركة |  |
| `required_role` | رتبة | لا | الرتبة المطلوبة للمطالبة بجائزة هذا السحب السريع |  |
| `message` | نص | لا | رسالة إضافية قبل السحب السريع |  |

إذا لم تُحدد `duration` فالمدة ساعة، وإذا لم تُحدد القناة فتُستخدم القناة الحالية. الحد الأقصى للفائزين 10 في الخطة المجانية و50 لخوادم Premium؛ `countdown` اختياري من 1 إلى 30 ثانية ويعرض عدًّا تنازليًا في القناة قبل النشر. الصور تقبل JPEG/JPG أو PNG أو GIF أو WEBP أو BMP أو TIFF. تتيح `required_role` المطالبة لأصحاب رتبة محددة فقط، ويُمنع أصحاب `blacklist_role`، وتُعرض `message` قبل السحب. عند انتهاء المدة تصبح أزرار المطالبة معطلة؛ تُعلن أسماء المطالبين كفائزين، وإذا لم يشارك أحد تظهر حالة انتهاء دون مشاركين. راجع [السحوبات السريعة وآخر من يكتب](/ar/giveaways/drops).

## /gfix

تشخيص سحب عالق أو ذي حالة غير متسقة وإصلاحه بأمان

**الصلاحية:** إدارة الخادم

| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `giveaway_id` | نص | نعم | معرّف رسالة السحب (أو رابط الرسالة) | إكمال تلقائي |
| `dry_run` | قيمة منطقية | لا | التشخيص فقط — دون تغيير أي شيء |  |

يجري الإصلاحات الآلية الآمنة ثم يعيد الفحص. الإجراءات التي تغيّر دورة حياة السحب تتطلب تأكيدًا عبر أزرار في التقرير، ويُعاد التحقق من الحالة عند التأكيد. مع `dry_run:true` يجري التشخيص فقط بلا تغييرات ولا أزرار تأكيد. يقبل معرّف الرسالة أو رابطها، ومتاح أيضًا كإجراء للرسالة باسم **إصلاح السحب**. راجع [رموز التشخيص](/ar/giveaways/managing#gfix-diagnose-and-repair).

## /settings

🎨 ضبط بوت السحوبات لهذا الخادم

**الصلاحية:** إدارة الخادم

يفتح لوحة تفاعلية خاصة مؤجلة الرد، ويتيح التنقل بقائمة بين الأقسام الآتية؛ تحفظ التغييرات وتنعكس اللوحة بعد التعديل. يتطلب الأمر صلاحية إدارة الخادم أو المسؤول أو رتبة مدير السحوبات.

| القسم | ما يتيحه |
| --- | --- |
| نظرة عامة | حالة Premium وملخص الرسائل الخاصة، وسلاسل الفائزين، والمظهر وطريقة المشاركة. |
| الرسائل الخاصة والقوالب | تشغيل/إيقاف رسالة الفائز ورسالة المضيف والرسالة العامة؛ تحرير قوالب الرسائل أو إعادة ضبطها. الرسالة العامة تفرض الرسائل الخاصة لكل السحوبات وتتجاوز خيار الإرسال عند الإنشاء. متغيرات القوالب: `{prize}` و`{server}` و`{winners_count}` و`{winners_list}` و`{timestamp}`. |
| سلسلة الفائزين | تشغيل إنشاء سلسلة تلقائية، اختيار عامة/خاصة، مدة الإغلاق التلقائي، متعقب المطالبة، مهلة المطالبة، والتنبيه للفائزين؛ مع تحرير الاسم والرسالة واللون وإعادة ضبط القيم. |
| زر الدخول | تغيير لون الزر بين Primary وSecondary وSuccess وDanger؛ تعيين/إعادة ضبط عنوان مخصص Premium (وإلا يظهر عدد المشاركين)، إخفاء/إظهار زر المشاركين، تقييد عرض المشاركين برتبة، وتخصيص زر المشاركين أو إعادته افتراضيًا. |
| المظهر | تعيين/إعادة ضبط لون التضمين، تسميات النهاية والمضيف والفائزين والمشاركين والرمز النقطي وقالب التضمين، وتخصيص رسائل إعلان الفوز وتأكيد الدخول والمغادرة أو إعادة ضبطها. القالب يدعم `{prize}` و`{host}` و`{end_time}` و`{winners_count}` و`{info_rows}` و`{extra}` و`{bullet}` و`{lbl_ends}` و`{lbl_host}` و`{lbl_winners}` و`{description}` و`{enter_button}`؛ ورسائل الإعلان تدعم `{prize}` و`{winners_list}` و`{winners_count}` و`{host}` و`{server}` و`{date}`. |
| طريقة الدخول | التبديل بين الزر والتفاعل برمز تعبيري؛ وضع التفاعل يتطلب Premium. ينطبق الخيار على السحوبات الجديدة فقط، ولا يغيّر الموجودة. |
| تخصيص البوت | لقب خاص بهذا الخادم؛ أما الصورة الرمزية واللافتة والنبذة فتغييرات على مستوى حساب البوت وتؤثر في جميع الخوادم. اللقب يتطلب Premium، والصورة واللافتة والنبذة Ultra Premium. |
| لوحة Premium | تعرض حالة الاشتراك ومستواه وموعد انتهائه وميزات الخطة. |

ميزات ضبط اللون، وضع التفاعل، تسميات الأزرار، وتخصيص السلاسل/المظهر موسومة بمتطلبات Premium في اللوحة. راجع [إعدادات الخادم](/ar/giveaways/settings).
