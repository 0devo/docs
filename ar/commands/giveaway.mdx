تتطلب أوامر إدارة السحوبات صلاحية **إدارة الخادم** أو **المسؤول** أو **رتبة مدير السحوبات**. راجع [الصلاحيات](/ar/concepts/permissions).

## /gcreate

إنشاء سحب باستخدام نموذج سريع

**الصلاحية:** إدارة الخادم أو المسؤول أو رتبة مدير السحوبات

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gcreate` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    لا يحتوي هذا الأمر على خيارات إلزامية.
  </Step>
  <Step title="أرسل الأمر">
    يظهر نموذج: أدخل الجائزة والمدة وعدد الفائزين، وأرفق صورة اختياريًا، ثم اختر **النشر الآن** أو **التخصيص في الاستوديو**.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gcreate
```
</CodeGroup>


<Info>
يفتح نموذجًا (نافذة منبثقة) يتضمن الجائزة (مطلوبة، حتى 256 حرفًا)، والمدة (مطلوبة)، وعدد الفائزين (مطلوب، افتراضيًا 1)، وصورة جائزة اختيارية (PNG أو JPG أو GIF أو WEBP، حتى 8 ميغابايت)، وخيارًا مطلوبًا لما يحدث بعد الإرسال: **النشر الآن** باستخدام مظهر الخادم وقواعده الافتراضية، أو **التخصيص في الاستوديو** لفتح لوحة `/gstart` معبأة بالقيم. تُفحص المدخلات قبل المتابعة؛ وعند الخطأ تظهر استجابة خاصة مع زر **تعديل وإعادة المحاولة** يعيد فتح النموذج مع الاحتفاظ بالإجابات. المدة المقبولة من 10 ثوانٍ إلى 90 يومًا، وتخضع حدود الفائزين والمدة لخطة Premium. يفحص الأمر القناة الحالية وصلاحيات البوت قبل فتح النموذج، وتنتهي صلاحية النموذج بعد 15 دقيقة. راجع [إنشاء السحوبات](/ar/giveaways/creating#gcreate-the-quick-form).
</Info>

## /gstart

بدء سحب بخيارات قابلة للتخصيص

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gstart` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    لا يحتوي هذا الأمر على خيارات إلزامية. الخيارات الاختيارية: `duration`, `winners`, `prize`, `template`, `channel`, `image`, `thumbnail`, `required_roles`….
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gstart
```
```text مثال أوسع
/gstart duration:1d winners:1 prize:Discord Nitro template:weekly-nitro
```
```text بالبادئة
g!gstart --duration=1d --winners=1 --prize=Discord Nitro
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `duration` | نص | لا | مدة السحب (مثل 1d، 2h، 30m) |  |
| `winners` | عدد صحيح | لا | عدد الفائزين |  |
| `prize` | نص | لا | الجائزة المقدمة في السحب |  |
| `template` | نص | لا | استخدام قالب محفوظ |  |
| `channel` | قناة | لا | القناة التي سيُقام فيها السحب |  |
| `image` | مرفق | لا | صورة للسحب |  |
| `thumbnail` | مرفق | لا | صورة مصغرة للسحب |  |
| `required_roles` | نص | لا | الرتب المطلوبة للمشاركة |  |
| `requirement_bypass_roles` | نص | لا | الرتب التي تتجاوز المتطلبات |  |
| `blacklist_roles` | نص | لا | الرتب المحظورة من المشاركة |  |
| `winners_roles` | نص | لا | الرتب الممنوحة للفائزين |  |
| `description` | نص | لا | وصف السحب |  |
| `host` | مستخدم | لا | المستخدم الذي يستضيف السحب |  |
| `giveaway_create_message` | نص | لا | رسالة مخصصة عند إنشاء السحب |  |
| `joined_age` | عدد صحيح | لا | الحد الأدنى لعدد الأيام التي يجب أن يكون المستخدم قد أمضاها في الخادم |  |
| `account_age` | عدد صحيح | لا | الحد الأدنى لعمر حساب المستخدم في Discord (بالأيام) |  |
| `required_messages` | عدد صحيح | لا | عدد الرسائل المطلوبة |  |
| `extra_entries` | نص | لا | فرص مشاركة إضافية للرتب (مثل @role 5) |  |
| `max_entries` | عدد صحيح | لا | الحد الأقصى لفرص المشاركة الإضافية التي يمكن للمستخدم كسبها من التصويت | النطاق: من 1 إلى 10 |
| `repeat` | عدد صحيح | لا | عدد مرات التكرار (Premium) | النطاق: من 1 دون حد أقصى |
| `sticky` | قيمة منطقية | لا | إعادة إرسال السحب تلقائيًا (Premium من المستوى 2 فأعلى) |  |
| `required_official_tag` | قيمة منطقية | لا | ما إذا كان يجب أن يحمل المستخدم وسم الخادم الرسمي |  |
| `required_level` | عدد صحيح | لا | الحد الأدنى للمستوى المطلوب للمشاركة (نظام المستويات) | النطاق: من 1 دون حد أقصى |
| `auto_claim` | قيمة منطقية | لا | المطالبة وإعادة السحب تلقائيًا: يطالب الفائزون بالجوائز بزر واحد؛ وتُعاد السحوبات تلقائيًا للجوائز التي لم يُطالب بها |  |

<Info>
راجع [إنشاء السحوبات](/ar/giveaways/creating) لمعرفة كيفية عمل كل مجموعة من الخيارات. تقبل خيارات قوائم الرتب إشارات الرتب أو معرّفاتها. تُؤخذ القيم غير المحددة من `template` المختار، ثم من الإعدادات الافتراضية للخادم.
</Info>

## /gdrop

بدء سحب سريع — أول من يطالب بالجائزة يفوز!

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gdrop` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    الخيارات الإلزامية: `prize`. الخيارات الاختيارية: `winners`, `duration`, `channel`, `image`, `thumbnail`, `countdown`, `blacklist_role`, `required_role`….
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/gdrop prize:Discord Nitro
```
```text مثال أوسع
/gdrop prize:Discord Nitro winners:1 duration:1d channel:#giveaways image:(attach a file)
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `prize` | نص | نعم | الجائزة المقدمة في السحب |  |
| `winners` | عدد صحيح | لا | عدد الفائزين (الافتراضي: 1) | النطاق: من 1 إلى 50 |
| `duration` | نص | لا | المدة (مثل 1h، 30m، 1d) |  |
| `channel` | قناة | لا | القناة التي سيُقام فيها السحب السريع |  |
| `image` | مرفق | لا | الصورة الرئيسية (صور فقط) |  |
| `thumbnail` | مرفق | لا | صورة مصغرة صغيرة (صور فقط) |  |
| `countdown` | عدد صحيح | لا | العد التنازلي قبل السحب السريع (1–30 ثانية) | النطاق: من 1 إلى 30 |
| `blacklist_role` | رتبة | لا | رتبة لا يمكنها المشاركة |  |
| `required_role` | رتبة | لا | الرتبة المطلوبة للمطالبة بجائزة هذا السحب السريع |  |
| `message` | نص | لا | رسالة إضافية قبل السحب السريع |  |

إذا لم تُحدد `duration` فالمدة ساعة، وإذا لم تُحدد القناة فتُستخدم القناة الحالية. الحد الأقصى للفائزين 10 في الخطة المجانية و50 لخوادم Premium؛ `countdown` اختياري من 1 إلى 30 ثانية ويعرض عدًّا تنازليًا في القناة قبل النشر. الصور تقبل JPEG/JPG أو PNG أو GIF أو WEBP أو BMP أو TIFF. تتيح `required_role` المطالبة لأصحاب رتبة محددة فقط، ويُمنع أصحاب `blacklist_role`، وتُعرض `message` قبل السحب. عند انتهاء المدة تصبح أزرار المطالبة معطلة؛ تُعلن أسماء المطالبين كفائزين، وإذا لم يشارك أحد تظهر حالة انتهاء دون مشاركين. راجع [السحوبات السريعة وآخر من يكتب](/ar/giveaways/drops).

## /greroll

إعادة السحب لاختيار فائز جديد أو أكثر من سحب منتهٍ

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/greroll` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    الخيارات الإلزامية: `giveaway_id`. الخيارات الاختيارية: `replace`, `count`, `exclude_previous_winners`. تعرض بعض الخيارات اقتراحات أثناء الكتابة؛ اختر منها.
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/greroll giveaway_id:123456789012345678
```
```text مثال أوسع
/greroll giveaway_id:123456789012345678 replace:@Winner count:2 exclude_previous_winners:true
```
```text بالبادئة
g!greroll 123456789012345678
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `giveaway_id` | نص | نعم | اختيار السحب المراد إعادة السحب فيه (أو لصق معرّف رسالة / رابط) | إكمال تلقائي |
| `replace` | مستخدم | لا | استبدال هذا الفائز فقط (مثلًا لعدم مطالبته بالجائزة) — يحتفظ بقية الفائزين بفوزهم |  |
| `count` | عدد صحيح | لا | عدد الفائزين الجدد المراد اختيارهم (يستبدل قائمة الفائزين بالكامل) | النطاق: من 1 دون حد أقصى |
| `exclude_previous_winners` | قيمة منطقية | لا | عدم اختيار أي شخص سبق له الفوز مطلقًا (الافتراضي: نعم) |  |

متاح أيضًا كإجراء للرسالة باسم **إعادة السحب**. راجع [الفائزون والمطالبة بالجوائز وإعادة السحب](/ar/giveaways/winners-and-claims#rerolling-manually-with-greroll).

## /glist

عرض السحوبات النشطة أو المنتهية في الخادم

**الصلاحية:** لا شيء (عرض القناة)

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/glist` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    لا يحتوي هذا الأمر على خيارات إلزامية. الخيارات الاختيارية: `status`, `host`, `channel`.
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة
/glist
```
```text مثال أوسع
/glist status:active host:@Host channel:#giveaways
```
```text بالبادئة
g!glist --status=active --host=@Host --channel=#giveaways
```
</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `status` | نص | لا | تصفية السحوبات حسب الحالة (نشطة أو منتهية أو مجدولة) | الخيارات: `active`، `ended`، `scheduled` |
| `host` | مستخدم | لا | تصفية السحوبات حسب المضيف |  |
| `channel` | قناة | لا | تصفية السحوبات حسب القناة |  |

يعرض النتائج خاصةً في صفحات، أربعة سجلات في الصفحة، مع روابط لرسائل السحب وأزرار حذف/إيقاف مؤقت أو استئناف/إعادة نشر بحسب الحالة؛ تنتهي صلاحية أزرار الجلسة بعد خمس دقائق. عامل `ended` يضم السجلات غير النشطة، و`scheduled` يعرض المجدولة. صلاحية الأمر عرض القناة.

## /gfix

تشخيص سحب عالق أو ذي حالة غير متسقة وإصلاحه بأمان

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">
    اكتب `/gfix` في قناة يستطيع البوت رؤيتها، ثم اخترْه من القائمة.
  </Step>
  <Step title="املأ الخيارات">
    الخيارات الإلزامية: `giveaway_id`. الخيارات الاختيارية: `dry_run`. تعرض بعض الخيارات اقتراحات أثناء الكتابة؛ اختر منها.
  </Step>
  <Step title="أرسل الأمر">
    يعرض البوت النتيجة.
  </Step>
</Steps>

<CodeGroup>
```text أبسط صيغة

```

</CodeGroup>


| الخيار | النوع | مطلوب | الوصف | ملاحظات |
| --- | --- | --- | --- | --- |
| `giveaway_id` | نص | نعم | معرّف رسالة السحب (أو رابط الرسالة) | إكمال تلقائي |

## /settings

🎨 ضبط بوت السحوبات لهذا الخادم

**الصلاحية:** إدارة الخادم

{/* usage */}
**طريقة الاستخدام**

<Steps>
  <Step title="افتح الأمر">


يفتح لوحة تفاعلية خاصة مؤجلة الرد، ويتيح التنقل بقائمة بين الأقسام الآتية؛ تحفظ التغييرات وتنعكس اللوحة بعد التعديل. يتطلب الأمر صلاحية إدارة الخادم أو المسؤول أو رتبة مدير السحوبات.

| القسم | ما يتيحه |
| --- | --- |
| نظرة عامة | حالة Premium وملخص الرسائل الخاصة، وسلاسل الفائزين، والمظهر وطريقة المشاركة. |
| الرسائل الخاصة والقوالب | تشغيل/إيقاف رسالة الفائز ورسالة المضيف والرسالة العامة؛ تحرير قوالب الرسائل أو إعادة ضبطها. الرسالة العامة تفرض الرسائل الخاصة لكل السحوبات وتتجاوز خيار الإرسال عند الإنشاء. متغيرات القوالب: `{prize}` و`{server}` و`{winners_count}` و`{winners_list}` و`{timestamp}`. |
| سلسلة الفائزين | تشغيل إنشاء سلسلة تلقائية، اختيار عامة/خاصة، مدة الإغلاق التلقائي، متعقب المطالبة، مهلة المطالبة، والتنبيه للفائزين؛ مع تحرير الاسم والرسالة واللون وإعادة ضبط القيم. |
| زر الدخول | تغيير لون الزر بين Primary وSecondary وSuccess وDanger؛ تعيين/إعادة ضبط عنوان مخصص Premium (وإلا يظهر عدد المشاركين)، إخفاء/إظهار زر المشاركين، تقييد عرض المشاركين برتبة، وتخصيص زر المشاركين أو إعادته افتراضيًا. |
| المظهر | تعيين/إعادة ضبط لون التضمين، تسميات النهاية والمضيف والفائزين والمشاركين والرمز النقطي وقالب التضمين، وتخصيص رسائل إعلان الفوز وتأكيد الدخول والمغادرة أو إعادة ضبطها. القالب يدعم `{prize}` و`{host}` و`{end_time}` و`{winners_count}` و`{info_rows}` و`{extra}` و`{bullet}` و`{lbl_ends}` و`{lbl_host}` و`{lbl_winners}` و`{description}` و`{enter_button}`؛ ورسائل الإعلان تدعم `{prize}` و`{winners_list}` و`{winners_count}` و`{host}` و`{server}` و`{date}`. |
| طريقة الدخول | التبديل بين الزر والتفاعل برمز تعبيري؛ وضع التفاعل يتطلب Premium. ينطبق الخيار على السحوبات الجديدة فقط، ولا يغيّر الموجودة. |
| تخصيص البوت | لقب خاص بهذا الخادم؛ أما الصورة الرمزية واللافتة والنبذة فتغييرات على مستوى حساب البوت وتؤثر في جميع الخوادم. اللقب يتطلب Premium، والصورة واللافتة والنبذة Ultra Premium. |
| لوحة Premium | تعرض حالة الاشتراك ومستواه وموعد انتهائه وميزات الخطة. |

ميزات ضبط اللون، وضع التفاعل، تسميات الأزرار، وتخصيص السلاسل/المظهر موسومة بمتطلبات Premium في اللوحة. راجع [إعدادات الخادم](/ar/giveaways/settings).
