## جميع الأوامر

**ملاحظة الصلاحيات:** يبيّن العمود صلاحية Discord المعتادة. تقبل أوامر إدارة السحوبات أيضًا رتبة Giveaway Manager المهيأة (واستثناءات مالك البوت/Administrator حيث ينطبق ذلك)؛ لذا فالصلاحية المعروضة ليست دائمًا المسار الوحيد. بعض الأوامر ذات صلاحية اسمية مثل «Administrator» تتحقق أيضًا داخل التنفيذ من أن المستخدم مالك/مطوّر البوت؛ الصلاحية الاسمية وحدها لا تمنح حق استخدامها.

| الفئة | الأمر | الوصف | من يمكنه استخدامه |
| --- | --- | --- | --- |
| السحوبات | `/gcreate` | إنشاء سحب بنموذج سريع (يتطلب صلاحية إدارة السحوبات) | Administrator / إدارة الخادم / Giveaway Manager |
| السحوبات | `/gdelete` | حذف سحب | إدارة الخادم |
| السحوبات | `/gdrop` | بدء سحب فوري — أول من يطالب بالجائزة يفوز! | إدارة الخادم |
| السحوبات | `/gedit` | تعديل سحب نشط أو مجدول | إدارة الخادم |
| السحوبات | `/gend` | إنهاء سحب نشط | إدارة الخادم |
| السحوبات | `/gfix` | تشخيص سحب عالق أو غير متسق وإصلاحه بأمان | إدارة الخادم |
| السحوبات | `/glast` | بدء سحب يفوز فيه أول أو آخر من يكتب | إدارة الخادم |
| السحوبات | `/glist` | عرض السحوبات النشطة أو المنتهية في الخادم | لا شيء (عرض القناة) |
| السحوبات | `/gpause` | إيقاف سحب جارٍ مؤقتًا (تجميد العد التنازلي) | إدارة الخادم |
| السحوبات | `/greroll` | إعادة اختيار فائز جديد أو أكثر من سحب منتهٍ | إدارة الخادم |
| السحوبات | `/gresume` | استئناف سحب متوقف مؤقتًا (استعادة الوقت المتبقي) | إدارة الخادم |
| السحوبات | `/gschedule` | جدولة سحب ليبدأ لاحقًا، مع معاينة مباشرة وإمكانية التعديل الكامل | إدارة الخادم |
| السحوبات | `/gstart` | بدء سحب بخيارات قابلة للتخصيص | إدارة الخادم |
| السحوبات | `/gtemplate` | إنشاء قوالب سحوبات قابلة لإعادة الاستخدام وإدارتها | إدارة الخادم |
| السحوبات | `/setcolor` | تعيين لون مخصص لتضمينات السحوبات (Premium فقط) | إدارة الخادم |
| السحوبات | `/setemoji` | تعيين رمز تعبيري مخصص لزر المشاركة في السحب (Premium فقط) | إدارة الخادم |
| السحوبات | `/settings` | 🎨 إعداد بوت السحوبات لهذا الخادم | إدارة الخادم |
| عام | `/afk` | تعيين حالة غيابك مع سبب اختياري | الجميع |
| عام | `/avatar` | الحصول على الصورة الرمزية وصورة الغلاف للمستخدم أو الخادم | الجميع |
| عام | `/counting` | فتح صفحة لعبة العد في لوحة الويب | إدارة الخادم |
| عام | `/levelsetup` | ⚙️ إعداد نظام المستويات عبر لوحة تفاعلية | إدارة الخادم |
| عام | `/rank` | معطّل مؤقتًا في تنفيذ البوت الحالي | الجميع |
| عام | `/server` | الحصول على معلومات الخادم | الجميع |
| عام | `/setlang` | تغيير لغة البوت لهذا الخادم | إدارة الخادم |
| عام | `/setlevel` | تعيين مستوى مستخدم في الخادم | إدارة الخادم |
| عام | `/setxp` | تعيين نقاط خبرة مستخدم في الخادم | إدارة الخادم |
| عام | `/starboard` | فتح إعدادات لوحة النجوم في لوحة الويب | إدارة الخادم |

| Premium | `/premium-removal` | إزالة اشتراك Premium من خادم (للمطورين فقط) | صلاحية مسجلة: Administrator؛ يتطلب داخليًا أن يكون المستخدم مالك/مطوّر البوت |

<Tip>
شغّل `/help` في Discord لعرض قائمة تفاعلية مصنفة، أو `/help command:<name>` لعرض مساعدة أمر واحد.
</Tip>
