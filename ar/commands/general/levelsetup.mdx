افتح لوحة إعداد المستويات التفاعلية. اللوحة تعرض الحالة الحالية، رتبة الاشتراك وحدوده، قناة الإشعارات، قيم XP، تتبع النشاط، المكافآت، المضاعفات، قوائم منع XP، أحداث التعزيز، إعدادات إعادة ضبط لوحة المتصدرين، رسائل الترقية والمظهر. التغييرات تحفظ عند تنفيذها؛ جلسة اللوحة مرتبطة بمستخدم وخادم وتنتهي بعد 20 دقيقة، وبعدها يلزم تشغيل الأمر من جديد. تظهر التفاعلات كردود خاصة.

**الصلاحية:** إدارة الخادم (`ManageGuild`) أو Administrator أو مالك البوت؛ الأمر للخوادم فقط.

{/* usage */}
**طريقة الاستخدام**

  <Step title="افتح الأمر">

  <Step title="املأ الخيارات">
    لا يحتوي هذا الأمر على خيارات إلزامية.

  </Step>
</Steps>

## أقسام وأزرار اللوحة

- **Enable / Disable:** تشغيل النظام أو إيقافه.
- **Channel:** ضبط قناة إشعار الترقية العامة، وقناتي إشعار منفصلتين للنص والصوت.
- **XP Config:** إعداد اكتساب XP، مثل XP الرسالة والتباين، XP دقيقة الصوت وفترة التهدئة؛ القيم المعروضة افتراضيًا عند عدم ضبطها هي 15 XP للرسالة، تباين 10، و10 XP لدقيقة الصوت و60 ثانية تهدئة.
- **LvlUp Msg:** إعداد رسائل الترقية للنص والصوت، واستخدام Embed أو الإرسال الخاص حيث تدعمه الإعدادات.
- **Color:** لون التمييز.
- **Role Rewards:** إضافة مكافأة رتبة تتطلب مستوى نص أو صوت أو كليهما؛ وضع المطابقة `all` يطلب كل مستوى محدد و`any` يكتفي بأحدهما. يمكن تعديل المكافآت ورسالتها الخاصة/إرسالها خاصًا وحذف واحدة أو مسح الكل. يتطلب كل إدخال رتبة ومستوى نصي أو صوتيًا واحدًا على الأقل، والمستوى بين 1 و999؛ الحد الأقصى لعدد المكافآت يتبع الخطة.
- **Multipliers:** ربط رتبة بمضاعف XP بين 0.1 و10؛ إضافة المضاعف يستبدل إعداد المضاعف السابق للرتبة نفسها.
- **No-XP Setup:** إدارة الرتب والقنوات والفئات المستثناة من XP.
- **XP Boost Event:** بدء حدث مضاعفة XP مع مضاعف ومدة وسبب اختياري؛ حدود المضاعف والمدة حسب الخطة، والمدة لا تقل عن ساعة.
- **Top Settings:** إعداد نوع لوحة المتصدرين ثابتًا أو متحركًا، أيام إعادة الضبط الأسبوعي والشهري والمنطقة الزمنية/أيام النافذة المتحركة بحسب الحقول المتاحة.
- **Profile Card:** إعداد خلفية بطاقة الملف الشخصي؛ رابط الخلفية يجب أن يبدأ بـ `http://` أو `https://`.
- **Advanced Settings:** تبديل تتبع النشاط النصي والصوتي، تجاهل المكتومين/المصمّتين، سياسة إزالة رتب المكافآت عند الترقية أو إعادة الضبط، إعطاء أعلى مكافأة فقط وحجب رتب الإدارة. تتبع الصوت والخلفيات المخصصة وبعض الرسائل/الميزات الأخرى مشروطة بمزايا Premium؛ الزر غير المتاح معطل.
- **Streaks:** تشغيل التتابع وضبط مكافأة النسبة لكل يوم وحدها؛ التحقق يقبل 0–100% لكل يوم و0–1000% كحد أعلى.
- **Reset Data:** حذف بيانات XP لمستخدم محدد أو إعادة ضبط بيانات XP لكل الخادم، مع طلب كتابة `CONFIRM` حرفيًا لإعادة ضبط الخادم. يمكن أيضًا مسح رتب المكافآت على حدة، ويتطلب ذلك التأكيد نفسه.
- **Reaction & Channels:** إعداد XP للتفاعلات ومكافآتها ومضاعفات القنوات وإشعارات الترقية. تعرض اللوحة قيمة افتراضية 5 ± 2 XP للتفاعل و30 ثانية تهدئة، ويمكن إدارة مضاعفات القنوات ومكافآت الرتب.
- **Premium Status:** عرض حالة الاشتراك وزر **Refresh**، مع **Back** للعودة.

لا تمنح اللوحة ميزات Premium غير المتاحة للخطة؛ تُعرض حالة القفل أو تُعطل الأزرار ذات الصلة. راجع [المستويات](/ar/features/leveling).
