---
title: "إجراءات النقر بزر الفأرة الأيمن"
description: "نفّذ الأوامر بالنقر بزر الفأرة الأيمن على عضو أو رسالة."
icon: "computer-mouse"
---

انقر بزر الفأرة الأيمن (أو اضغط مطولًا على الهاتف) على عضو أو رسالة، ثم اختر **التطبيقات**.

## على الأعضاء

| الإجراء | وظيفته |
| --- | --- |
| الصورة الشخصية | عرض صورته الشخصية. |
| معلومات المستخدم | عرض معلومات عنه. |
| الرتبة | عرض بطاقة رتبته. |
| منح نقطة سمعة | منحه نقطة سمعة. |
| تغيير اللقب | تغيير لقبه. |
| التحدي في حجر ورقة مقص | تحديه في لعبة حجر ورقة مقص. |
| التحدي في إكس أو | تحديه في لعبة إكس أو. |

## على الرسائل

| الإجراء | وظيفته |
| --- | --- |
| معلومات الرسالة | عرض معلومات عن الرسالة. |
| ترجمة الرسالة | ترجمتها. راجع [الترجمة](/ar/features/translate). |
| نسخ رمز تعبيري | نسخ رمز تعبيري من الرسالة إلى خادمك. |

## على رسائل السحوبات

<Info>
تتطلب هذه الإجراءات الصلاحية نفسها التي يتطلبها الأمر المقابل. راجع [الصلاحيات](/ar/concepts/permissions).
</Info>

| الإجراء | الأمر المقابل |
| --- | --- |
| إعادة اختيار الفائزين في السحب | `/greroll` |
| تعديل السحب | `/gedit` |
| حذف السحب | `/gdelete` |
| إيقاف السحب مؤقتًا | `/gpause` |
| استئناف السحب | `/gresume` |
| إنهاء السحب | `/gend` |
| إصلاح السحب | `/gfix` |
